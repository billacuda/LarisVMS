# 儲存空間與保留

錄影存放在哪裡、保留多久、水位線和封存磁碟區。

## 儲存路徑

每個節點錄製到自己的**儲存路徑**，在節點的編輯頁面或安裝時設定。沒有全域路徑。沒有儲存路徑的節點不會錄製任何內容，節點清單會標出它。

## 保留

**保留**是錄影保留的天數。它在**設定 → 儲存空間與保留**下全域設定，並可以依節點和依攝影機覆寫；最具體的值優先。0 表示永久保留錄影。

攝影機還可以設定以 GB 為單位的**儲存空間配額**。超出時，會先刪除其最舊的錄影。

## 水位線

**水位線**是節點磁碟可以寫到多滿的硬性限制（預設 90%）。超過它時，節點會提前封存其最舊的錄影，如果無法封存則刪除，直到磁碟回落到限制以下。發生這種情況時，節點清單會顯示**儲存空間已滿**。

## 封存

節點可以有選用的第二個**封存路徑**，例如 SMB 共用或 USB 隨身碟。它必須與儲存路徑是不同的位置。開啟封存後，超出保留期的錄影會被**移動**到封存，而不是被刪除，並保留到達到**封存保留期**為止。封存保留期從原始錄影日期開始計算，0 表示永久保留。

回放、縮圖和匯出無論從哪個磁碟區都以相同方式運作。節點清單顯示兩個磁碟區的可用空間和剩餘天數的估計值。該估計基於過去 24 小時的寫入量。

## 殘留的錄影

當攝影機移到另一個節點或被移除時，其舊錄影會保留在之前的節點上，直到過期。節點狀態旁的 ⚠️ 數字顯示有多少台攝影機在那裡仍有錄影。它會自行清除。

## 加密

錄影可以在錄影節點的磁碟上加密，這樣被盜或丟棄的磁碟什麼也看不到。預設關閉。

在**設定 → 加密與簽署**下**設定**它：

1. **建立主金鑰**。它保存在此伺服器上，並能解鎖所有加密的錄影。
2. **下載主金鑰的備份**，由您選擇的通關密語保護。在您擁有備份之前，無法開啟加密。請把檔案和通關密語保存在此伺服器以外的地方：如果伺服器被重建，用備份**還原**是再次讀取加密錄影的唯一辦法。兩者都遺失，錄影就永遠遺失了。
3. **選擇要加密的內容**：「**影像**」（錄影和雙向通話音訊），或「**影像、快照和縮圖**」。這是每台攝影機的預設值；每台攝影機都可以在自己的頁面（**攝影機 → 編輯**，儲存空間）上覆寫它。

每個片段在錄影結束後不久就會在錄影節點上加密，因此磁碟上只有正在錄製的片段是未加密的。開啟加密之前錄製的錄影保持原樣；攝影機頁面上的**加密現有錄影**會在背景轉換它們。之後關閉加密，已加密的錄影仍然可以讀取。

回放、縮圖、快照和匯出的運作方式與以前相同。匯出的檔案不加密，因為它們本來就是要交給別人的。錄影節點在需要時從此伺服器取得每台攝影機的每日金鑰，並且只儲存在記憶體中，因此當錄影節點無法連線伺服器時，無法播放加密的錄影。
