# 錄影

錄影模式、排程、事件標籤、預錄和後錄，以及片段長度。

## 模式

每台攝影機都會持續錄影到其節點。**錄影模式**決定*保留*哪些錄影：

| 模式 | 保留 |
|---|---|
| **連續** | 所有內容。 |
| **移動偵測** | 移動前後的錄影：來自移動偵測區域、攝影機自身的移動事件、某個整合，或 AI 偵測（請參閱[移動偵測](/Help/motion#source)）。 |
| **排程** | 在已啟用的排程時段內開始的錄影。 |
| **事件** | 在已開啟*觸發錄影*的事件標籤規則前後的錄影。 |
| **僅手動** | 除非開啟了[手動錄影](#manual-recording)，否則不保留任何內容。其餘時間攝影機只用於即時檢視。 |

未被保留的錄影會在寫入後不久被刪除，而不是等待保留期。

移動偵測、排程和事件模式是**失效放行**的。在攝影機設定好移動偵測區域、排程時段或觸發規則之前，它會保留所有內容，而不是丟棄。發生這種情況時，攝影機頁面會發出警告。僅手動不是失效放行，因為什麼都不保留正是它的用途。

在**設定 → 錄影預設值**下設定全域模式，並在攝影機頁面上覆寫它。

## 手動錄影

無論攝影機的錄影模式為何，手動錄影都會保留攝影機的錄影，直到有人停止它。使用[即時圖塊](/Help/live-and-playback#live-tiles)上的錄影按鈕或透過 [API](/Help/api#recording) 開始。它在重新啟動和升級後仍保持開啟。

它與攝影機的模式並行運作。移動偵測攝影機在看到移動*或*手動錄影開啟時保留錄影，事件仍照常在時間軸上加上標籤。在連續攝影機上，它只會在時間軸上標記。

- 錄影按完整片段保留，因此錄影前後最多各有一個片段也會被儲存。預錄和後錄不適用。
- 儲存的錄影遵循攝影機的一般保留原則。加入[證據鎖定](/Help/live-and-playback#evidence-locks)可保留更久。
- 它在時間軸上顯示為紅色條帶。在**設定 → 事件**下變更顏色。
- 離線的攝影機在恢復之前不會儲存任何內容。錄影保持開啟。
- 請將錄影節點與伺服器一起升級。舊節點不知道手動錄影。

## 預錄和後錄

在移動偵測和事件模式下，**預錄**是活動之前保留多少錄影（這樣您能看到有人走進來），**後錄**是活動結束後保留多少。

## 片段長度

錄影以固定長度（預設 60 秒）的檔案寫入。回放必須先下載片段的一部分，才能從您選擇的確切時刻開始。較短的片段使高解析度攝影機的定位更快，但會產生更多檔案。變更長度會短暫重新啟動攝影機的錄影。

## 排程

攝影機的**排程**頁面包含其時段：日期、開始時間和結束時間。結束時間早於開始時間表示跨越午夜。時間使用**錄影節點的本機時鐘**。時段只在排程模式下有意義。

## 事件標籤

攝影機的**事件標籤**頁面會將來自攝影機的 ONVIF 事件（移動、警報、分析、竄改）轉換為時間軸上的彩色標記。

- **起始主題**：啟動標籤的事件。從*已觀察到的主題*中選擇一個，它列出了攝影機實際傳送過的所有內容。
- **停止主題**：選用。當起始主題自帶真/假狀態時（大多數移動和警報主題都是如此），請留空。當攝影機分別傳送開始和停止事件時再設定它。
- **觸發錄影**：在事件或移動偵測模式下，保留此標籤前後的錄影。

標籤只有在其停止事件到達時才會結束，絕不會因逾時而結束。
