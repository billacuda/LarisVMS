# 攝影機

新增攝影機、攝影機清單、串流、裝置設定、群組、多鏡頭裝置和廠商整合。

## 新增攝影機

使用**攝影機 → 探索**掃描區域網路中的 ONVIF 裝置，或使用**攝影機 → 新增**輸入裝置服務 URL（例如 `http://192.168.1.50/onvif/device_service`）和憑證。然後 LarisVMS 會**探測**攝影機：讀取其 ONVIF 功能和串流，並選擇主串流和子串流。

請指派一個**錄影節點**，否則攝影機不會錄影。

## 攝影機清單

**攝影機**列出您能看到的每台攝影機。欄標題下方的那一列可依任意欄（如廠牌、型號、節點或群組）篩選，表格上方的搜尋方塊則依列內任意位置的文字篩選。篩選條件可以組合，**清除篩選**會重設它們。**欄**用於選擇顯示哪些欄。針對隱藏欄的篩選會被忽略。

您的篩選、欄、排序順序和頁面大小會儲存到您的帳戶，因此在任何裝置上再次登入時都會還原。

勾選攝影機即可一次對多台進行操作：**將所選項目重新指派到節點**，或對同一廠牌和型號的攝影機使用**裝置設定…**（請參閱[批次變更](#bulk-changes)）。**全選**只會選取符合目前篩選條件的攝影機。

## 重新探測

攝影機頁面上的**重新探測**會重新讀取其功能和串流。在攝影機自己的網頁上變更解析度、編解碼器或韌體之後，請執行此操作。在[裝置設定](#device-settings)中所做的變更會自動重新探測。變更裝置 URL 並儲存時也會自動重新探測。**設定 → 攝影機設定**可以每天重新探測一次所有攝影機。攝影機是逐台探測的，因此廉價攝影機不會中斷其錄影工作階段。重新探測時，串流名稱和啟用旗標會被保留。

## 串流

每台攝影機通常有一個**主串流**（完整解析度，用於錄影）和一個**子串流**（較低解析度，用於小型即時圖塊和 AI 偵測）。展開攝影機頁面上的**裝置**可重新命名或停用某個串流。將滑鼠停留在串流上可檢視其 RTSP URL。LarisVMS 使用新增攝影機時所用的位址，並保留攝影機回報的連接埠和路徑，因此回報內部位址的攝影機（或冒充它的人）無法攜帶密碼把錄影節點引向別處。

## 裝置設定

攝影機頁面上的**裝置設定**透過 ONVIF 變更攝影機自身的設定，因此您無需登入攝影機的網頁。設定是從攝影機即時讀取的，只顯示它所支援的設定。

| 區段 | 設定 |
|---|---|
| **影像串流** | 每個串流：編解碼器（H.264、H.265 或 MJPEG）、編碼設定檔、解析度、畫面更新率、位元率模式（CBR 或 VBR）、位元率、品質和關鍵影格間隔 |
| **影像** | 亮度、對比、飽和度和銳利度；日夜模式；WDR；背光補償；曝光模式；以及白平衡 |
| **音訊** | 編解碼器、位元率和取樣率 |

每個區段都有自己的**套用**按鈕，並且只會傳送您變更過的設定。套用串流或音訊的變更會使串流重新連線，在錄影中留下幾秒鐘的空白；隨後 LarisVMS 會重新探測攝影機，錄影節點會立即採用新格式。影像變更無需重新連線即可生效。

有些攝影機在串流之間共用同一組編碼器設定。頁面會註明這一點，因為變更其中一個會改變另一個。

H.265 和 CBR/VBR 的選擇需要支援 ONVIF Profile T（Media2）的攝影機。在較舊的攝影機上不會出現這些選項。

## 批次變更

一次變更同一廠牌和型號的多台攝影機：

1. 在**攝影機**上，篩選**型號**欄，然後勾選這些攝影機（或**全選**）。
2. 按一下**裝置設定…**。僅當所有勾選的攝影機是同一廠牌和型號時才可用。
3. 變更您需要的內容，並按一下該區段的**套用**。

您也可以從某一台攝影機的**裝置設定**頁面開始，並在**同時將變更套用到**下選擇同型號的其他攝影機。**韌體不同**徽章會標出韌體不同的攝影機，它們提供的選項可能略有不同。

頁面顯示第一台攝影機的目前設定。只有您變更的設定會傳送給每台攝影機，因此每台攝影機自身的其餘設定保持不變。串流依角色（主串流、子串流或第三串流）比對。每台攝影機會根據自身的選項檢查該變更，結果清單會依攝影機顯示它是已套用、部分套用、已略過（例如沒有第三串流的攝影機）還是失敗（例如離線）。**重試失敗項目**會向失敗的攝影機再次傳送該變更。

## 群組

群組將攝影機依站點、建築和樓層整理。**頂層群組即站點**，其下的群組是建築或樓層。一台攝影機可以屬於任意數量的群組，只要它們都屬於同一個站點。群組用於篩選、設定覆寫以及[攝影機存取](/Help/users#camera-access)。內建的*所有攝影機*群組一律包含每台攝影機。

## 多通道

有些裝置在一個外殼裡有多個鏡頭。當探測發現多個影像來源時，攝影機頁面會提供**拆分為 N 台攝影機**。此後每個鏡頭都成為自己的攝影機，擁有各自的錄影和保留。現有攝影機成為通道 1，並保留其錄影。

## 整合

有些功能無法透過 ONVIF 使用。整合（列在**設定 → 外掛程式**下）會在探測期間根據攝影機的廠牌和型號自動比對，無需開啟任何開關。例如，**Dahua / Amcrest 智慧事件**整合會從攝影機自帶的分析中讀取人員和車輛偵測。當整合生效時，攝影機的**裝置**面板會顯示。
