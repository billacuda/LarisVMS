# 概觀

LarisVMS 各部分如何協同運作：Web 伺服器、錄影節點、媒體代理和攝影機。

## 各個組成部分

| 組成部分 | 作用 |
|---|---|
| **Web 伺服器** | LarisVMS 的 Web 應用程式。將設定儲存在 SQL Server 或 MariaDB 中，提供介面和 API，並在未開啟直連串流時轉送即時和回放影像。以 *LarisVMS Web* Windows 服務執行。 |
| **錄影節點** | 每台錄影電腦上的 Windows 服務。從其攝影機拉取 RTSP，將片段寫入其儲存路徑，執行保留原則，執行移動偵測和 AI 偵測，並回報健康狀況。一台伺服器可以有多個節點。 |
| **視覺服務** | 節點的選用子程序，在節點的 GPU（或 CPU）上執行 AI 物件偵測。這裡當機永遠不會使錄影停止。 |
| **媒體代理** | 瀏覽器與節點之間的選用轉送，適用於遠端站點或低頻寬連線。 |
| **攝影機** | ONVIF 攝影機。每台攝影機指派給一個錄影節點。 |

## 影像如何流轉

1. 節點向其每台攝影機建立 RTSP 工作階段，並使用 `ffmpeg -c copy` 錄製，因此不會發生重新編碼。
2. 錄影以短片段檔案的形式寫入節點的儲存路徑下（請參閱[錄影](/Help/recording)）。
3. 即時檢視和回放由節點提供，並經由此伺服器、媒體代理轉送，或直接傳送到瀏覽器（請參閱[節點](/Help/nodes#direct-streaming)）。

## 隱私

LarisVMS 是自行託管的：您的影像和設定保留在您自己的電腦上，不會收集或共用任何有關您安裝的資訊。沒有遙測，也不會對外回傳。唯一的例行對外要求，是每天檢查一次 LarisVMS 的 GitHub 發行頁面是否有新版本（請參閱[更新](/Help/installation#updates)）；它可以關閉。另一項內建下載，是偵測首次使用時從該專案的 GitHub 發行頁面下載的 YOLOX AI 模型，除非您自己把檔案放到伺服器上。[地圖](/Help/live-and-playback#map)頁面上的街道地圖會在您的瀏覽器中從 OpenStreetMap 或您選擇的圖磚伺服器載入地圖圖片；平面圖則不會。其他所有內容只會傳送到您的攝影機、您自己的伺服器，以及您設定的服務（如電子郵件和警示管道）。

## 設定繼承

大多數設定存在於三個層級。最具體的一級優先：

1. **攝影機**：在攝影機自己的編輯頁面上。
2. **節點**：在**節點**下該節點的編輯頁面上。
3. **全域**：在對應的**設定**頁面上。

留空的欄位（或「繼承 — …」選項）使用上一層級的值，並顯示它目前繼承的值。

## 儀表板

儀表板由小工具組成。每位使用者選擇自己的小工具，版面配置會儲存到其帳戶，因此在其他瀏覽器上也會保持一致。

- **自訂**（右上角；當視窗太窄無法顯示完整格線時隱藏）會解鎖版面配置。拖曳標題列移動小工具，拖曳角落調整大小，或用 × 移除。**新增小工具**會列出所有可新增的內容，**重設版面配置**會恢復預設。完成後按一下**完成**。
- 自訂期間，每個小工具都有可以移動和調整大小的按鈕，無需拖曳。
- **暫停更新**可在您閱讀時讓小工具停止變化。
- 大多數小工具是攝影機或節點的前 10 名清單，例如已用儲存空間、畫面更新率、頻寬、最舊錄影、離線攝影機、距上次錄影的時間和偵測。有些帶有時間範圍（1h、24h、7d、30d），有些可以在最高和最低優先之間切換。
- 按一下小工具的標題可開啟其完整報告：每台攝影機或節點，每頁 100 筆，帶篩選方塊、節點篩選、可排序的欄和 CSV 下載。
- **攝影機活動**以依時段劃分的熱度圖顯示一台攝影機過去 7 天的情況；在其標題列中選擇攝影機，按一下標題可開啟完整的[活動](/Help/live-and-playback#activity)頁面。
- **最新偵測**顯示最新的快照。其 ⚙ 按鈕用於選擇包含哪些偵測類型；一般移動（未辨識出任何內容）預設關閉，除非您勾選它。
- **距上次錄影的時間**會標出設為連續錄影、但已超過 5 分鐘沒有錄影的攝影機。
- 基於攝影機的節點小工具（攝影機數量、離線攝影機、畫面更新率、剩餘儲存時間）會排除沒有攝影機的節點。
- 您只能看到自己有權存取的攝影機。**最近的警示**僅提供給可以管理警示規則的使用者。

小工具每分鐘重新整理一次。

## 在手機上

整個網站都可以在手機瀏覽器中使用。側邊欄透過左上角的 ☰ 按鈕開啟。

若要將其安裝為應用程式，請在 Android 上用 Chrome 開啟該網站，並從 ⋮ 選單中選擇**安裝應用程式**。在 iOS 上，請用 Safari 開啟，並選擇**分享 → 加入主畫面**。該應用程式會全螢幕開啟，沒有瀏覽器的網址列。

安裝需要手機信任的憑證。瀏覽器不會安裝使用全新安裝時自我簽署憑證的網站；請參閱[憑證](/Help/security#certificates)。
