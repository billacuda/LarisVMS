# 語言

以另一種語言顯示 LarisVMS，並新增您自己的翻譯。

## 選擇語言

從任意頁面（包括登入頁面）頂端的 🌐 選單中選擇一種語言。您的選擇會跟隨您，套用於您登入的每台裝置。只有安裝了多於一種語言時，才會出現該選單。

管理員在**設定 → 語言**下為尚未選擇語言的所有人設定語言。保持為**瀏覽器的語言**，則改為跟隨每個人的瀏覽器。

日期、時間和數字也會跟隨語言。如果您的瀏覽器使用相同的語言但帶有地區格式（例如英式英語），則會保留該地區格式。

警示和通知會以每個人自己的語言送達。團隊管道（傳送到固定地址的電子郵件、Webhook、ntfy、Pushover、Slack 和 Teams）使用預設語言。稽核記錄保持為英文。

某種語言尚未翻譯的文字會以英文顯示。

## 新增語言

無需程式設計：一種語言就是一個文字檔案。

1. 在**設定 → 語言**下，下載英文文字 **en.json**。
2. 翻譯每行右側的文字。左側的鍵請保持原樣。
3. 在**設定 → 語言**下上傳該檔案，或將其複製到伺服器上的 `%ProgramData%\LarisVMS\locales`。請以其語言代碼命名，例如 `fr.json`、`de.json` 或 `pt-BR.json`。

它立即可用，無需重新啟動。無法讀取的檔案會連同原因一起列在「語言」頁面上，LarisVMS 的其餘部分繼續正常運作。

### 需要保持原樣的內容

- **大括號 { } 中的任何內容**都由 LarisVMS 填入，例如 `{camera}` 或 `{count}`。請把它移到句子中合適的位置，但不要翻譯或重新命名它。
- **少數標籤**可能出現在文字中：`<code>`、`<strong>`、`<em>`、`<b>`、`<i>`、`<kbd>`、`<br>` 和 `<a href="…">`。請讓它們仍然包圍相同的詞。其他 HTML 不被允許，並會顯示為純文字。
- 頂端的 **_meta** 區段包含該語言在 🌐 選單中顯示的名稱（例如「Français」），以及您的姓名（如果您希望署名）。

### 複數

有些文字會隨數字變化。英語有兩種形式：

```json
"cameras.count_one": "{count} camera",
"cameras.count_other": "{count} cameras"
```

請新增您的語言所需的形式，使用以下結尾：`_zero`、`_one`、`_two`、`_few`、`_many` 和 `_other`。例如，俄語使用 `_one`、`_few` 和 `_many`。請始終包含 `_other`；在沒有其他形式適用時會使用它。

### 說明頁面

說明頁面逐個檔案翻譯。每個頁面保持英文檔案的名稱，因此其位址不會變化，您沒有翻譯的頁面仍保持為英文。地區語言（`es-AR`）先使用自己的頁面，然後是通用語言（`es`）的頁面，最後是英文。

- **用於您自己的伺服器**：將頁面的 Markdown 以相同的檔案名稱複製到 `locales\<code>\help\`（例如 `locales\fr\help\03-cameras.md`），然後翻譯它。
- **為 LarisVMS 貢獻**：關於如何提交，請參閱 [CONTRIBUTING.md](https://github.com/billacuda/LarisVMS/blob/main/CONTRIBUTING.md)。翻譯後的頁面保存在原始碼中的 `src/LarisVMS.Web/Help/<code>/`（例如 `Help/es-AR/03-cameras.md`），與 `Help/en/` 中的英文頁面並列。貢獻的頁面隨 LarisVMS 一起發行，也會出現在 [larisvms.com/docs](https://www.larisvms.com/docs/)，訪客可以在那裡選擇語言。

只要安裝了某種語言（其 `.json` 檔案），說明就會以該語言顯示。頁面中的 HTML 會顯示為純文字，因此請使用 Markdown 來設定格式。

### 更新翻譯

LarisVMS 的新版本會增加文字。「語言」頁面上的**已翻譯**欄顯示每種語言涵蓋了多少目前文字，**說明頁面**則顯示它有自己文字的說明頁面數量。語言旁邊的**下載**會提供其檔案，其中缺失的文字已用英文補全，可以直接翻譯。

在上傳檔案之前檢查它，請執行 `tools\locale-check.ps1 fr.json`。它會列出缺失的鍵、此版本未使用的鍵，以及與英文文字不符的 {預留位置}。加上 `-Help` 並指定一個已翻譯說明頁面的資料夾（例如 `-Help locales\fr\help`），還可以檢查這些頁面：尚未翻譯的頁面、LarisVMS 不使用的檔案名稱、HTML，以及與英文頁面不對應的標題。

### 測試翻譯

在**設定 → 語言**下開啟**在語言選單中提供偽語言**，然後從 🌐 選單中選擇它。每段文字都會帶上重音符號並加長約三分之一，例如 `[Ŝàṽé ··]`。仍以純英文顯示的文字尚無法翻譯；請回報。溢出按鈕或欄的文字需要更短的翻譯，或修正版面配置。

### 從右到左書寫的語言

阿拉伯語、希伯來語、波斯語和其他從右到左書寫的語言會獲得鏡像版面配置：選單移到右側，文字和按鈕向右對齊。攝影機畫面、時間軸和地圖不會鏡像。

### 翻譯安裝程式

Web、節點和代理安裝程式有它們自己的、短得多的文字，位於原始碼中的 `installer\Common\Strings.en-US.wxl`。請將其複製為以語言命名的檔案（例如 `Strings.fr-FR.wxl`），並按檔案頂端的說明操作。然後使用 `.\build-installers.ps1 -Cultures en-US,fr-FR` 建置安裝程式，為每種語言產生一套安裝程式。Windows 自帶的安裝程式按鈕（下一步、上一步、取消等）已經翻譯。

## 語言檔案存放在哪裡

- `%ProgramData%\LarisVMS\locales` 存放在此伺服器上新增的語言。升級後依然保留。
- 伺服器安裝資料夾中的 `locales` 存放隨 LarisVMS 提供的語言。在此伺服器上新增的檔案，會逐行優先於這裡的同名檔案。
- 英文是內建的，無法取代。

上傳或移除語言會記錄到稽核記錄，並且需要變更設定的權限。
