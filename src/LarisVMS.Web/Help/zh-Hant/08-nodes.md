# 節點

錄影節點：狀態、串流路徑、媒體代理、容錯移轉、維護和更新。

側邊欄中的**節點**會列出每個節點及其狀態、位址、版本、攝影機數量和磁碟使用情況。按一下節點可編輯其設定。**⋯** 選單有以下動作：

- **重新啟動服務**：重新啟動節點的 Windows 服務，而不是重新啟動電腦。錄影會暫停幾秒鐘。
- **重設驗證**：清除節點的簽到權杖，用於錯過心跳後一直驗證失敗的節點。對正常節點沒有影響。
- **維護**：將節點的攝影機移到其備用節點，直到您關閉維護。
- **刪除**：移除節點。其攝影機會變為未指派。錄影不會被刪除。

如果節點在最近 2 分鐘內簽到過，則為**線上**。⚠️ **時鐘**警告表示節點的時鐘與伺服器的時鐘相差超過一分鐘，請檢查其時間同步。

## 直連串流

預設情況下，所有即時和回放影像都經由 Web 伺服器轉送（**代理**）。使用**直連**時，瀏覽器會直接連線到每個節點自己的 HTTPS 端點，從而減輕伺服器的負擔。在**設定 → 即時檢視**下設定模式，並可依節點覆寫。

直連模式需要瀏覽器可以存取的**用戶端端點主機**，以及一個憑證（節點頁面上的 `.pfx` 路徑）。**允許自我簽署**僅用於測試，因為檢視者會看到瀏覽器警告。節點沒有正常端點的攝影機會自動回復為代理。

## 來自伺服器的加密連線

伺服器和媒體代理透過節點即時連接埠（8554）上的一般 HTTP 存取每個節點的影像和控制路由，這在受信任的網路上沒有問題。若要加密該流量，請在節點頁面上開啟**加密來自伺服器的連線**，然後重新啟動節點一次（**重新啟動**）。節點會啟動其 HTTPS 端點（如果沒有 `.pfx`，則使用其自己的自我簽署憑證）並回報該憑證，伺服器隨後會固定它：伺服器和代理只接受節點的這一個憑證，媒體權杖也不再是位址的一部分。加密之後，節點的一般連接埠只回應 `/health`。

節點頁面上的**已加密**欄會為每個已加密的節點顯示 🔒，為已開啟但仍需重新啟動的節點顯示 ⏳。開關下方的狀態會顯示所用的憑證，或伺服器仍在等待它（在此之前，伺服器會繼續使用一般 HTTP，因此不會有任何功能停止運作）。預設關閉。為此使用的自我簽署憑證永遠不會提供給瀏覽器；直連串流仍然需要正式的憑證。

## 代理

**媒體代理**是瀏覽器與節點之間的獨立轉送（`LarisVMS.Proxy`），適用於遠端站點或低頻寬連線。在**設定 → 媒體代理**下註冊代理，然後在每個節點的頁面上選擇主要代理和備用代理。瀏覽器會使用第一個正常的代理。

## 容錯移轉

為節點指定一個**備用錄影節點**，當它停機時，其攝影機會由備用節點錄製，直到它恢復。「停機」由該節點的夥伴節點、伺服器和它的代理之間的投票來判定。**維護**會有意將其攝影機移過去並保持在那裡。

當備用節點的 AI 硬體不同，或僅用於錄影時，節點頁面會發出警告。在這些情況下，容錯移轉期間偵測可能變慢或暫停。

## 更新

節點和代理會從已核准的版本自動更新（請參閱[安裝](/Help/installation#updates)）。**節點 → 更新與註冊 → 自動更新**用於對所有節點開啟或關閉此功能。

節點頁面的**版本**區段顯示每種節點正在升級到的版本，以及任何等待核准的版本，帶有**核准**和**拒絕**。**版本歷程記錄**列出每個版本，包括已核准、已取代和已拒絕的。

## 伺服器憑證

**節點 → 更新與註冊 → 伺服器憑證檢查**決定節點和代理如何檢查此伺服器的 HTTPS 憑證：

- **首次使用時信任**（預設）：受信任 CA 簽發的憑證一律有效，包括續期和更換後的憑證。自我簽署憑證會在節點首次連線時被記住，只要它保持不變就會一直有效，即使過了到期日期。如果它發生變化，節點和代理會拒絕它，直到被重新註冊。
- **僅限受信任的憑證**：只接受由受信任 CA 簽發、且與伺服器名稱相符的憑證。選擇此項之前請先安裝一個。
- **不檢查**：任何憑證。不安全：網路路徑上的任何人都可以冒充伺服器。

使用「首次使用時信任」時，節點會信任它首次連線時看到的任何憑證。若要讓它從最初的連線起就進行檢查，請把**伺服器憑證檢查**下顯示的指紋傳給安裝程式：對 `install-node.ps1` 和 `install-proxy.ps1` 使用 `-ServerCertThumbprint`，對 MSI 使用 `SERVERCERTTHUMBPRINT=`。安裝精靈頁面和媒體代理頁面上的安裝命令已經包含它。在反向代理之後，請改用反向代理所出示憑證的指紋。

伺服器為自己產生的自我簽署憑證有效期為 10 年，不會自動更換。**重新產生自我簽署憑證**會取代它；之後每個節點和代理都必須重新註冊，節點頁面會列出此後沒有簽到的節點。要重新註冊節點，請再次執行節點安裝程式，或在節點上執行 `LarisVMS.Node.exe --reset-server-pin` 並重新啟動其服務（代理也有相同的選項）。

## 一次性註冊代碼

新節點和代理使用共用的**註冊金鑰**或一次性代碼來註冊。一次性代碼只能註冊一個節點或代理，之後即失效。未使用時，它會在 1 小時、24 小時或 7 天後到期。要建立一個，請前往**節點 → 更新與註冊**，選擇它的有效時長，並選擇**建立代碼**。代碼只顯示一次。請在安裝程式要求輸入註冊金鑰的地方使用它。**撤銷**會取消尚未使用的代碼。

共用金鑰在被變更之前對每次安裝都有效。一旦您使用一次性代碼，請取消勾選**接受共用註冊金鑰**，這樣舊指令碼或電子郵件中的金鑰副本就無法註冊任何內容。已經註冊的節點和代理不受影響。無論哪種方式，新節點在獲得任何攝影機之前仍需等待核准。
