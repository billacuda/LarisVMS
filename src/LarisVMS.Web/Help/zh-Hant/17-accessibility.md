# 協助工具

使用鍵盤、螢幕閱讀程式或您自己的顯示設定來使用 LarisVMS。

## 鍵盤

每個頁面都以**跳到主要內容**連結開頭，按 Tab 鍵時會出現。

| 位置 | 按鍵 |
|---|---|
| 即時和檢視圖塊 | 用 Tab 鍵可到達圖塊的控制項，到達時控制項會出現 |
| PTZ 按鈕 | 按住 Enter 或空白鍵移動，放開則停止 |
| 時間軸 | 左右方向鍵微調時間，Page Up 和 Page Down 跳轉，+ 和 - 縮放 |
| 回放中的目前時間 | Enter 鍵開啟一個欄位，用於輸入精確的時間 |
| 區域、隱私遮罩、測速點和塗黑 | 方向鍵移動游標（Shift 可加大步長），空白鍵點選，Enter 鍵完成圖形，Backspace 鍵移除最後一個點 |
| 儀表板和檢視版面配置 | 每一項都有用於移動和調整大小的按鈕 |
| 地圖 | 在攝影機上按 Enter 鍵將其放到地圖中間，然後使用移動按鈕 |

要移動圖形上的某個點，請在其上按空白鍵，移動游標，然後再次按空白鍵。滑鼠的用法相同：按一下一個點，然後按一下它應該移到的位置。

要在不拖曳的情況下繪製塗黑矩形，請按一下一個角，然後按一下對角。

## 螢幕閱讀程式

控制項、表單欄位和狀態訊息都帶有供螢幕閱讀程式使用的標籤，頁面載入時會播報錯誤。您檢視中某個圖塊上的手動錄影開始或停止時也會播報。

「活動」頁面上的確切數值可以用表格查看：開啟圖表上方的表格選項即可。

影像本身是視覺內容。每個影像都以其攝影機命名，但畫面顯示的內容無法自動描述。

## 不依靠顏色查看時間軸

時間軸區段除了顏色之外，還透過圖案來區分：

- **空白**：沒有錄影。
- **實心**：已有錄影。
- **條紋**：有移動或事件的錄影。

## 顯示設定

- **主題**：LarisVMS 跟隨您裝置的淺色或深色設定，也可以使用頁面頂端的 🌙 按鈕。
- **文字大小**：瀏覽器中更大的預設字型大小在這裡同樣適用，並且瀏覽器縮放在每個頁面上都有效。
- **減少動態效果**：如果您的裝置要求減少動態效果，動畫就會關閉。
- **高對比**：支援 Windows 對比主題。

在**設定 → 品牌**下，如果所選的顏色難以閱讀，LarisVMS 會發出警告。自訂顏色適用於所有人，因此請謹慎選擇。

## 暫停更新

使用儀表板上的**暫停更新**，可以在您閱讀時讓小工具停止變化。即時影像會繼續播放，因為這正是該頁面的用途。

## 限制

- **字幕和音訊描述**：攝影機不錄製字幕或音訊描述，因此播放程式沒有相關控制項。
- **無法目視時的繪製**：攝影機畫面上的圖形可以透過鍵盤繪製，但放置位置需要靠肉眼判斷。
- **圖塊時間軸**：即時圖塊上的小型時間軸可透過滑鼠滾輪、雙指縮放或 + 和 - 鍵縮放。回放中的完整時間軸還帶有縮放按鈕。
