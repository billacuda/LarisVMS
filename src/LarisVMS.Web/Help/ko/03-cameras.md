# 카메라

카메라 추가, 카메라 목록, 스트림, 장치 설정, 그룹, 다중 렌즈 장치, 제조사 연동을 설명합니다.

## 카메라 추가

**카메라 → 검색**으로 LAN에서 ONVIF 장치를 스캔하거나, **카메라 → 추가**에서 장치 서비스 URL(예: `http://192.168.1.50/onvif/device_service`)과 자격 증명을 입력합니다. 그런 다음 LarisVMS가 카메라를 **프로브**합니다. ONVIF 기능과 스트림을 읽고 메인 스트림과 서브 스트림을 선택합니다.

**녹화 노드**를 할당하십시오. 할당하지 않으면 카메라가 녹화되지 않습니다.

## 카메라 목록

**카메라**에는 볼 수 있는 모든 카메라가 나열됩니다. 열 제목 아래 행에서는 제조사, 모델, 노드, 그룹 등 어느 열로든 필터링할 수 있고, 표 위의 검색 상자는 행의 어디에 있든 텍스트로 필터링합니다. 필터는 함께 적용되며 **필터 지우기**로 초기화됩니다. **열**에서 표시할 열을 선택합니다. 숨겨진 열의 필터는 무시됩니다.

필터, 열, 정렬 순서, 페이지 크기는 계정에 저장되므로 어떤 기기에서든 다시 로그인하면 복원됩니다.

카메라를 선택하면 여러 대를 한꺼번에 처리할 수 있습니다. **선택 항목을 노드에 다시 할당**, 또는 제조사와 모델이 같은 카메라용 **장치 설정**…입니다([일괄 변경](#bulk-changes) 참조). **모두 선택**은 현재 필터와 일치하는 카메라만 선택합니다.

## 다시 프로브

카메라 페이지의 **다시 프로브**는 기능과 스트림을 다시 읽습니다. 카메라 자체 웹 페이지에서 해상도, 코덱, 펌웨어를 변경한 후에 사용하십시오. [장치 설정](#device-settings)에서 변경한 내용은 자동으로 다시 프로브됩니다. 장치 URL을 변경하면 저장할 때 자동으로 다시 프로브됩니다. **설정 → 카메라 설정**에서는 하루에 한 번 모든 카메라를 다시 프로브할 수 있습니다. 카메라는 한 번에 하나씩 프로브되므로 저가형 카메라의 녹화 세션이 끊기지 않습니다. 스트림 이름과 사용 설정 플래그는 다시 프로브해도 유지됩니다.

## 스트림

각 카메라에는 보통 **메인** 스트림(전체 해상도, 녹화에 사용)과 **서브** 스트림(낮은 해상도, 작은 라이브 타일과 AI 감지에 사용)이 있습니다. 스트림 이름을 바꾸거나 사용 안 함으로 하려면 카메라 페이지에서 **장치**를 펼치십시오. 스트림 위에 마우스를 올리면 RTSP URL이 표시됩니다. LarisVMS는 카메라를 추가할 때 사용한 주소를 사용하고 카메라가 보고하는 포트와 경로를 유지하므로, 내부 주소를 보고하는 카메라(또는 그것을 사칭하는 무언가)가 비밀번호와 함께 녹화 노드를 다른 곳으로 보낼 수 없습니다.

## 장치 설정

카메라 페이지의 **장치 설정**은 ONVIF를 통해 카메라 자체의 설정을 변경하므로 카메라의 웹 페이지에 로그인할 필요가 없습니다. 설정은 카메라에서 실시간으로 읽으며 카메라가 지원하는 항목만 표시됩니다.

| 섹션 | 설정 |
|---|---|
| **영상 스트림** | 스트림별로 코덱(H.264, H.265, MJPEG), 인코딩 프로필, 해상도, 프레임 속도, 비트레이트 모드(CBR 또는 VBR), 비트레이트, 품질, 키프레임 간격 |
| **이미지** | 밝기, 대비, 채도, 선명도, 주야 모드, WDR, 역광 보정, 노출 모드, 화이트 밸런스 |
| **오디오** | 코덱, 비트레이트, 샘플 레이트 |

각 섹션에는 자체 **적용** 버튼이 있으며 변경한 설정만 전송됩니다. 스트림이나 오디오 변경을 적용하면 스트림이 다시 연결되어 녹화에 몇 초의 공백이 생깁니다. 그 후 LarisVMS가 카메라를 다시 프로브하고 녹화 노드가 새 형식을 즉시 반영합니다. 이미지 변경은 다시 연결하지 않고 적용됩니다.

일부 카메라는 스트림 간에 인코더 설정을 하나로 공유합니다. 하나를 바꾸면 다른 것도 바뀌므로 페이지에 그렇게 표시됩니다.

H.265와 CBR/VBR 선택에는 ONVIF Profile T(Media2)를 지원하는 카메라가 필요합니다. 오래된 카메라에서는 이 옵션이 표시되지 않습니다.

## 일괄 변경

제조사와 모델이 같은 여러 카메라를 한 번에 변경하려면:

1. **카메라**에서 **모델** 열을 필터링한 다음 카메라를 선택합니다(또는 **모두 선택**).
2. **장치 설정**…을 클릭합니다. 선택한 모든 카메라가 같은 제조사와 모델일 때만 사용할 수 있습니다.
3. 필요한 항목을 변경하고 해당 섹션에서 **적용**을 클릭합니다.

카메라 한 대의 **장치 설정** 페이지에서 시작하여 **변경 사항을 다음에도 적용**에서 같은 모델의 다른 카메라를 선택할 수도 있습니다. **펌웨어가 다름** 배지는 펌웨어가 다른 카메라를 표시하며, 이런 카메라는 옵션이 조금 다를 수 있습니다.

페이지에는 첫 번째 카메라의 현재 설정이 표시됩니다. 변경한 설정만 각 카메라로 전송되므로 각 카메라의 나머지 설정은 그대로 유지됩니다. 스트림은 역할(메인, 서브, 서드)로 짝지어집니다. 각 카메라는 변경 사항을 자체 옵션에 맞춰 확인하며, 결과 목록에는 카메라별로 적용됨, 일부 적용됨, 건너뜀(예: 서드 스트림이 없는 카메라), 실패(예: 오프라인) 중 무엇인지 표시됩니다. **실패한 항목 다시 시도**는 실패한 카메라에 변경 사항을 다시 보냅니다.

## 그룹

그룹은 카메라를 사이트, 건물, 층으로 구성합니다. **최상위 그룹이 사이트**이고 그 아래 그룹이 건물이나 층입니다. 카메라는 모두 같은 사이트에 속하는 한 몇 개의 그룹에든 속할 수 있습니다. 그룹은 필터링, 설정 재정의, [카메라 접근](/Help/users#camera-access)에 사용됩니다. 기본 제공 *모든 카메라* 그룹에는 항상 모든 카메라가 들어 있습니다.

## 다중 채널

일부 장치는 하나의 본체에 여러 렌즈가 있습니다. 프로브에서 비디오 소스가 둘 이상 발견되면 카메라 페이지에 **{N}대의 카메라로 분할**이 표시됩니다. 분할하면 각 렌즈가 자체 녹화와 보존을 가진 별도의 카메라가 됩니다. 기존 카메라는 채널 1이 되며 녹화는 유지됩니다.

## 연동

ONVIF로는 제공되지 않는 기능이 있습니다. 연동(**설정 → 플러그인**에 나열됨)은 프로브 중에 카메라의 제조사와 모델에서 자동으로 일치됩니다. 따로 켤 것은 없습니다. 예를 들어 **Dahua / Amcrest 스마트 이벤트** 연동은 카메라 자체 분석에서 사람과 차량 감지를 읽습니다. 연동이 활성 상태이면 카메라의 **장치** 패널에 표시됩니다.
