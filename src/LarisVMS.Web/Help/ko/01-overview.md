# 개요

LarisVMS의 구성 요소(웹 서버, 녹화 노드, 미디어 프록시, 카메라)가 어떻게 연결되는지 설명합니다.

## 구성 요소

| 구성 요소 | 역할 |
|---|---|
| **웹 서버** | LarisVMS 웹 앱입니다. 설정을 SQL Server 또는 MariaDB에 저장하고, UI와 API를 제공하며, 직접 스트리밍이 켜져 있지 않으면 라이브 및 재생 영상을 중계합니다. *LarisVMS Web* Windows 서비스로 실행됩니다. |
| **녹화 노드** | 녹화를 담당하는 각 컴퓨터에서 실행되는 Windows 서비스입니다. 카메라에서 RTSP를 가져와 저장 경로에 세그먼트를 기록하고, 보존 정책을 적용하며, 모션 및 AI 감지를 실행하고, 상태를 보고합니다. 서버 하나에 여러 노드를 둘 수 있습니다. |
| **비전 서비스** | 노드의 GPU(또는 CPU)에서 AI 객체 감지를 실행하는 노드의 선택적 하위 프로세스입니다. 여기서 문제가 생겨도 녹화는 멈추지 않습니다. |
| **미디어 프록시** | 원격 사이트나 저대역폭 회선을 위해 브라우저와 노드 사이에 두는 선택적 중계입니다. |
| **카메라** | ONVIF 카메라입니다. 각 카메라는 하나의 녹화 노드에 할당됩니다. |

## 영상의 흐름

1. 노드는 각 카메라에 RTSP 세션을 열고 `ffmpeg -c copy`로 녹화하므로 재인코딩이 일어나지 않습니다.
2. 영상은 노드의 저장 경로 아래에 짧은 세그먼트 파일로 기록됩니다([녹화](/Help/recording) 참조).
3. 라이브 보기와 재생은 노드가 제공하며, 이 서버, 미디어 프록시를 거치거나 브라우저로 바로 전달됩니다([노드](/Help/nodes#direct-streaming) 참조).

## 개인정보

LarisVMS는 자체 호스팅입니다. 영상과 설정은 사용자의 컴퓨터 안에 머물며, 설치에 대한 어떤 정보도 수집되거나 공유되지 않습니다. 원격 측정이나 외부 호출도 없습니다. 정기적으로 나가는 유일한 요청은 새 버전이 있는지 LarisVMS의 GitHub 릴리스를 하루에 한 번 확인하는 것이며([업데이트](/Help/installation#updates) 참조) 끌 수 있습니다. 또 다른 기본 제공 다운로드는 감지가 처음 YOLOX 모델을 사용할 때 해당 프로젝트의 GitHub 릴리스에서 받는 YOLOX AI 모델이며, 파일을 서버에 직접 넣어 두면 받지 않습니다. [지도](/Help/live-and-playback#map) 페이지의 거리 지도는 OpenStreetMap 또는 사용자가 선택한 타일 서버에서 브라우저가 지도 이미지를 불러옵니다. 평면도는 그렇지 않습니다. 그 밖의 모든 통신은 카메라, 사용자의 서버, 이메일이나 알림 채널처럼 사용자가 설정한 서비스로만 나갑니다.

## 설정 상속

대부분의 설정은 세 단계에 있으며, 가장 구체적인 단계가 우선합니다.

1. **카메라**: 카메라 자체의 편집 페이지.
2. **노드**: **노드** 아래 노드의 편집 페이지.
3. **전역**: 해당 **설정** 페이지.

비워 둔 항목(또는 "상속 — …" 옵션)은 한 단계 위의 값을 사용하며, 현재 상속하는 값을 표시합니다.

## 대시보드

대시보드는 위젯으로 구성됩니다. 각 사용자가 자신의 위젯을 선택하고 레이아웃은 계정에 저장되므로 다른 브라우저에서도 따라옵니다.

- **사용자 지정**(오른쪽 위. 창이 너무 좁아 전체 그리드를 표시할 수 없으면 숨겨짐)은 레이아웃 잠금을 해제합니다. 위젯은 제목 표시줄을 끌어 이동하고, 모서리를 끌어 크기를 조정하며, ×로 제거합니다. **위젯 추가**에는 추가할 수 있는 모든 항목이 표시되고, **레이아웃 초기화**는 기본값으로 되돌립니다. 마치면 **완료**를 클릭하십시오.
- 사용자 지정하는 동안 각 위젯에는 끌지 않고도 이동하고 크기를 조정할 수 있는 버튼이 있습니다.
- **업데이트 일시 중지**는 읽는 동안 위젯이 바뀌지 않게 합니다.
- 대부분의 위젯은 카메라나 노드의 상위 10개 목록입니다. 예를 들어 사용 중인 저장소, 프레임 속도, 대역폭, 가장 오래된 영상, 오프라인 카메라, 마지막 녹화 이후 경과 시간, 감지 등이 있습니다. 일부는 시간 범위(1h, 24h, 7d, 30d)가 있으며, 일부는 높은 순과 낮은 순을 전환할 수 있습니다.
- 위젯 제목을 클릭하면 전체 보고서가 열립니다. 모든 카메라 또는 노드가 페이지당 100개씩 표시되며, 필터 상자, 노드 필터, 정렬 가능한 열, CSV 다운로드가 있습니다.
- **카메라 활동**은 한 카메라의 지난 7일을 시간대별 히트맵으로 보여 줍니다. 제목 표시줄에서 카메라를 선택하고, 제목을 클릭하면 전체 [활동](/Help/live-and-playback#activity) 페이지가 열립니다.
- **최신 감지**는 가장 최근 스냅샷을 표시합니다. ⚙ 버튼으로 포함할 감지 유형을 선택합니다. 일반 모션(식별된 것이 없는 경우)은 체크하지 않으면 꺼져 있습니다.
- **마지막 녹화 이후 경과 시간**은 연속 녹화로 설정된 카메라가 5분 넘게 녹화하지 않았을 때 표시합니다.
- 카메라를 기반으로 하는 노드 위젯(카메라 수, 오프라인 카메라, 프레임 속도, 남은 저장 시간)은 카메라가 없는 노드를 제외합니다.
- 접근 권한이 있는 카메라만 표시됩니다. **최근 알림**은 알림 규칙을 관리할 수 있는 사용자에게만 제공됩니다.

위젯은 1분마다 새로 고쳐집니다.

## 휴대폰에서

사이트 전체가 휴대폰 브라우저에서 작동합니다. 사이드바는 왼쪽 위의 ☰ 버튼으로 엽니다.

앱으로 설치하려면 Android에서는 Chrome으로 사이트를 열고 ⋮ 메뉴에서 **앱 설치**를 선택하십시오. iOS에서는 Safari로 열고 **공유 → 홈 화면에 추가**를 선택하십시오. 앱은 브라우저 주소 표시줄 없이 전체 화면으로 열립니다.

설치하려면 휴대폰이 신뢰하는 인증서가 필요합니다. 새 설치가 처음 사용하는 자체 서명 인증서를 쓰는 사이트는 브라우저에서 설치할 수 없습니다. [인증서](/Help/security#certificates)를 참조하십시오.
