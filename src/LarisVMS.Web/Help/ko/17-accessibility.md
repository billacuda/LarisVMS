# 접근성

키보드, 화면 낭독기 또는 자신의 디스플레이 설정으로 LarisVMS를 사용하는 방법을 설명합니다.

## 키보드

모든 페이지는 Tab을 누르면 나타나는 **본문으로 건너뛰기** 링크로 시작합니다.

| 위치 | 키 |
|---|---|
| 라이브 및 보기 타일 | Tab으로 타일의 컨트롤에 이동하면 컨트롤이 나타남 |
| PTZ 버튼 | Enter 또는 Space를 누르고 있으면 이동하고, 놓으면 중지 |
| 타임라인 | 왼쪽/오른쪽 화살표로 시간을 미세 조정하고, Page Up과 Page Down으로 건너뛰고, +와 -로 확대/축소 |
| 재생의 현재 시각 | Enter를 누르면 정확한 시각을 입력하는 필드가 열림 |
| 영역, 개인정보 마스크, 속도 측정, 가림 처리 | 화살표 키로 커서를 이동(Shift로 더 크게), Space로 클릭, Enter로 도형 완료, Backspace로 마지막 점 제거 |
| 대시보드 및 보기 레이아웃 | 각 항목에 이동 및 크기 조정 버튼이 있음 |
| 지도 | 카메라에서 Enter를 누르면 지도 중앙에 배치되고, 이후 이동 버튼 사용 |

도형의 점을 옮기려면 그 점에서 Space를 누르고, 커서를 이동한 다음 Space를 다시 누르십시오. 마우스도 같은 방식입니다. 점을 클릭한 다음 옮길 위치를 클릭하십시오.

끌지 않고 가림 처리 사각형을 그리려면 한쪽 모서리를 클릭한 다음 반대쪽 모서리를 클릭하십시오.

## 화면 낭독기

컨트롤, 양식 필드, 상태 메시지에는 화면 낭독기용 레이블이 있으며, 오류는 페이지가 로드될 때 안내됩니다. 보기의 타일에서 수동 녹화가 시작되거나 중지될 때도 안내됩니다.

활동 페이지의 정확한 값은 표로 볼 수 있습니다. 차트 위의 표 옵션을 켜십시오.

영상 자체는 시각적입니다. 각 영상에는 카메라 이름이 붙어 있지만 화면에 무엇이 보이는지는 자동으로 설명할 수 없습니다.

## 색상 없이 타임라인 보기

타임라인 구간은 색상뿐 아니라 패턴으로도 구분됩니다.

- **비어 있음:** 영상 없음.
- **채워짐:** 영상이 녹화되었습니다.
- **줄무늬:** 모션 또는 이벤트가 있는 영상.

## 디스플레이 설정

- **테마:** LarisVMS는 기기의 밝은/어두운 설정을 따르며, 페이지 상단의 🌙 버튼을 사용할 수도 있습니다.
- **텍스트 크기:** 브라우저의 기본 글꼴 크기를 키우면 여기에도 적용되며, 브라우저 확대/축소는 모든 페이지에서 작동합니다.
- **동작 줄이기:** 기기가 움직임을 줄이도록 요청하면 애니메이션이 꺼집니다.
- **고대비:** Windows 대비 테마를 지원합니다.

**설정 → 브랜딩**에서는 선택한 색상이 읽기 어려우면 LarisVMS가 경고합니다. 사용자 지정 색상은 모든 사용자에게 적용되므로 신중하게 선택하십시오.

## 업데이트 일시 중지

대시보드의 **업데이트 일시 중지**를 사용하면 읽는 동안 위젯이 바뀌지 않습니다. 라이브 영상은 이 페이지의 목적이므로 계속 재생됩니다.

## 제한 사항

- **자막과 화면 해설:** 카메라는 자막이나 화면 해설을 녹화하지 않으므로 플레이어에는 이를 위한 컨트롤이 없습니다.
- **시각 없이 그리기:** 카메라 화면 위의 도형은 키보드로 그릴 수 있지만, 배치는 눈으로 확인해야 합니다.
- **타일 타임라인:** 라이브 타일의 작은 타임라인은 마우스 휠, 핀치 또는 + 및 - 키로 확대/축소합니다. 재생의 전체 타임라인에는 확대/축소 버튼도 있습니다.
