# 언어

LarisVMS를 다른 언어로 표시하고 직접 번역을 추가하는 방법을 설명합니다.

## 언어 선택

로그인 페이지를 포함한 모든 페이지 상단의 🌐 메뉴에서 언어를 선택하십시오. 선택 내용은 로그인하는 모든 기기에 따라옵니다. 메뉴는 둘 이상의 언어가 설치된 경우에만 나타납니다.

언어를 선택하지 않은 모든 사용자의 언어는 관리자가 **설정 → 언어**에서 정합니다. 각 사용자의 브라우저를 따르게 하려면 **브라우저의 언어**로 두십시오.

날짜, 시간, 숫자도 언어를 따릅니다. 브라우저가 같은 언어의 지역 형식(예: 영국 영어)을 사용하면 지역 형식이 유지됩니다.

알림은 각 사람에게 그 사람의 언어로 전달됩니다. 팀 채널(고정 주소로의 이메일, 웹훅, ntfy, Pushover, Slack, Teams)은 기본 언어를 사용합니다. 감사 로그는 영어로 유지됩니다.

언어에 아직 번역되지 않은 텍스트는 영어로 표시됩니다.

## 언어 추가

프로그래밍은 필요하지 않습니다. 언어는 텍스트 파일 하나입니다.

1. **설정 → 언어**에서 영어 텍스트인 **en.json**을 다운로드합니다.
2. 각 줄의 오른쪽 텍스트를 번역합니다. 왼쪽의 키는 그대로 두십시오.
3. 파일을 **설정 → 언어**에서 업로드하거나, 서버의 `%ProgramData%\LarisVMS\locales`에 복사합니다. 파일 이름은 언어 코드(예: `fr.json`, `de.json`, `pt-BR.json`)로 지정하십시오.

다시 시작하지 않아도 바로 사용할 수 있습니다. 읽을 수 없는 파일은 이유와 함께 언어 페이지에 나열되며, LarisVMS의 나머지는 계속 작동합니다.

### 그대로 두어야 하는 것

- **{중괄호} 안의 모든 것**은 `{camera}`나 `{count}`처럼 LarisVMS가 채웁니다. 문장 안에서 알맞은 위치로 옮겨도 되지만, 번역하거나 이름을 바꾸지 마십시오.
- **일부 태그**가 텍스트에 나타날 수 있습니다: `<code>`, `<strong>`, `<em>`, `<b>`, `<i>`, `<kbd>`, `<br>`, `<a href="…">`. 같은 단어를 감싼 채로 두십시오. 다른 HTML은 허용되지 않으며 일반 텍스트로 표시됩니다.
- 맨 위의 **_meta** 섹션에는 🌐 메뉴에 표시되는 언어 이름(예: "Français")과, 원하면 크레딧을 위한 본인의 이름이 들어 있습니다.

### 복수형

일부 텍스트는 숫자에 따라 바뀝니다. 영어에는 두 가지 형태가 있습니다.

```json
"cameras.count_one": "{count} camera",
"cameras.count_other": "{count} cameras"
```

언어에 필요한 형태를 다음 접미사로 추가하십시오: `_zero`, `_one`, `_two`, `_few`, `_many`, `_other`. 예를 들어 러시아어는 `_one`, `_few`, `_many`를 사용합니다. `_other`는 항상 포함하십시오. 다른 형태가 맞지 않을 때 사용됩니다.

### 도움말 페이지

도움말 페이지는 파일 하나씩 번역합니다. 각 페이지는 영어 파일의 이름을 유지하므로 주소가 바뀌지 않으며, 번역하지 않은 페이지는 영어로 남습니다. 지역 언어(`es-AR`)는 자체 페이지를 먼저 사용하고, 그다음 일반 언어(`es`)의 페이지, 그다음 영어를 사용합니다.

- **자신의 서버용:** 페이지의 Markdown을 같은 파일 이름(예: `locales\fr\help\03-cameras.md`)으로 `locales\<code>\help\`에 복사하여 번역하십시오.
- **LarisVMS에 기여하려면:** 보내는 방법은 [CONTRIBUTING.md](https://github.com/billacuda/LarisVMS/blob/main/CONTRIBUTING.md)를 참조하십시오. 번역된 페이지는 소스의 `src/LarisVMS.Web/Help/<code>/`(예: `Help/es-AR/03-cameras.md`)에 `Help/en/`의 영어 페이지 옆에 보관됩니다. 기여된 페이지는 LarisVMS와 함께 배포되며, 방문자가 언어를 선택할 수 있는 [larisvms.com/docs](https://www.larisvms.com/docs/)에도 나타납니다.

도움말은 해당 언어가 설치되어 있으면(그 `.json` 파일) 그 언어로 표시됩니다. 페이지의 HTML은 일반 텍스트로 표시되므로 서식에는 Markdown을 사용하십시오.

### 번역 업데이트

LarisVMS의 새 버전은 텍스트를 추가합니다. 언어 페이지의 **번역됨** 열은 각 언어가 현재 텍스트를 얼마나 다루는지, **도움말 페이지**는 자체 텍스트가 있는 도움말 페이지가 몇 개인지 보여 줍니다. 언어 옆의 **다운로드**는 부족한 텍스트를 영어로 채운, 번역할 준비가 된 파일을 줍니다.

업로드하기 전에 파일을 확인하려면 `tools\locale-check.ps1 fr.json`을 실행하십시오. 누락된 키, 이 버전에서 사용하지 않는 키, 영어 텍스트와 일치하지 않는 {자리 표시자}가 나열됩니다. 번역된 도움말 페이지 폴더(예: `-Help locales\fr\help`)와 함께 `-Help`를 추가하면 그것들도 확인합니다. 아직 번역되지 않은 페이지, LarisVMS가 사용하지 않는 파일 이름, HTML, 영어 페이지와 맞지 않는 제목이 대상입니다.

### 번역 테스트

**설정 → 언어**에서 **언어 메뉴에 의사 로캘 표시**를 켠 다음 🌐 메뉴에서 선택하십시오. 모든 텍스트가 악센트와 함께 약 3분의 1 더 길게 `[Ŝàṽé ··]`처럼 표시됩니다. 일반 영어로 계속 표시되는 텍스트는 아직 번역할 수 없는 것이므로 알려 주십시오. 버튼이나 열을 넘치는 텍스트는 더 짧은 번역이나 레이아웃 수정이 필요합니다.

### 오른쪽에서 왼쪽으로 쓰는 언어

아랍어, 히브리어, 페르시아어 등 오른쪽에서 왼쪽으로 쓰는 언어는 거울상 레이아웃이 적용됩니다. 메뉴는 오른쪽으로 이동하고 텍스트와 버튼은 오른쪽에 맞춰 정렬됩니다. 카메라 화면, 타임라인, 지도는 반전되지 않습니다.

### 설치 프로그램 번역

웹, 노드, 프록시 설치 프로그램에는 소스 코드의 `installer\Common\Strings.en-US.wxl`에 훨씬 짧은 자체 텍스트가 있습니다. 이를 언어 이름으로 된 파일(예: `Strings.fr-FR.wxl`)로 복사하고 파일 맨 위의 안내를 따르십시오. 그러면 설치 프로그램은 `.\build-installers.ps1 -Cultures en-US,fr-FR`로 빌드되며 언어마다 설치 프로그램 세트가 만들어집니다. Windows 자체의 설치 프로그램 버튼(다음, 뒤로, 취소 등)은 이미 번역되어 있습니다.

## 언어 파일 위치

- `%ProgramData%\LarisVMS\locales`에는 이 서버에서 추가한 언어가 있습니다. 업그레이드해도 유지됩니다.
- 서버 설치 폴더의 `locales`에는 LarisVMS와 함께 제공되는 언어가 있습니다. 이 서버에서 추가한 파일은 여기의 같은 이름 파일보다 줄 단위로 우선합니다.
- 영어는 기본 제공이며 교체할 수 없습니다.

언어 업로드 또는 제거는 감사 로그에 기록되며 설정을 변경할 권한이 필요합니다.
