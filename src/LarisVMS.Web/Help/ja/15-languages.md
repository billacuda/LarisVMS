# 言語

LarisVMS を別の言語で表示する方法と、ご自身の翻訳を追加する方法について説明します。

## 言語を選択する

サインインページを含む、どのページの上部にある 🌐 メニューから、言語を選択します。選択内容は、サインインするすべてのデバイスに引き継がれます。メニューは、2 つ以上の言語がインストールされている場合にのみ表示されます。

言語を選んでいない全員に対する言語は、管理者が**設定 → 言語**で設定します。各自のブラウザーに従うには、**ブラウザーの言語**のままにしてください。

日付、時刻、数値も、言語に従います。ブラウザーが、同じ言語の地域別の形式（たとえば英国英語）を使っている場合は、その地域別の形式が維持されます。

アラートと通知は、各自の言語で届きます。チームチャンネル（固定アドレスへのメール、Webhook、ntfy、Pushover、Slack、Teams）は、既定の言語を使用します。監査ログは英語のままです。

言語でまだ翻訳されていないテキストは、英語で表示されます。

## 言語を追加する

プログラミングは不要です。言語は、1 つのテキストファイルです。

1. **設定 → 言語**で、英語のテキストである **en.json** をダウンロードします。
2. 各行の右側のテキストを翻訳します。左側のキーは、そのままにしてください。
3. ファイルを**設定 → 言語**でアップロードするか、サーバーの `%ProgramData%\LarisVMS\locales` にコピーします。ファイル名は、言語コード（たとえば `fr.json`、`de.json`、`pt-BR.json`）にしてください。

再起動せずに、すぐに利用できます。読み取れないファイルは、理由とともに言語ページに一覧表示され、LarisVMS のそのほかの部分は引き続き機能します。

### そのままにしておくもの

- **{波かっこ} で囲まれた部分**は、`{camera}` や `{count}` のように、LarisVMS が値を埋め込みます。文の中の適切な位置に移動して構いませんが、翻訳や名前の変更はしないでください。
- **一部のタグ**がテキストに含まれることがあります: `<code>`、`<strong>`、`<em>`、`<b>`、`<i>`、`<kbd>`、`<br>`、`<a href="…">`。同じ語句を囲んだままにしてください。それ以外の HTML は許可されず、プレーンテキストとして表示されます。
- 上部の **_meta** セクションには、🌐 メニューに表示される言語の名前（たとえば「Français」）と、クレジットを希望する場合はあなたの名前を入力します。

### 複数形

一部のテキストは、数によって変わります。英語には 2 つの形があります。

```json
"cameras.count_one": "{count} camera",
"cameras.count_other": "{count} cameras"
```

言語に必要な形を、次の末尾で追加します: `_zero`、`_one`、`_two`、`_few`、`_many`、`_other`。たとえばロシア語では、`_one`、`_few`、`_many` を使用します。`_other` は必ず含めてください。ほかの形が当てはまらない場合に使用されます。

### ヘルプページ

ヘルプページは、1 ファイルずつ翻訳します。各ページは、英語のファイル名をそのまま使用するため、アドレスは変わらず、翻訳していないページは英語のままです。地域別の言語（`es-AR`）は、まず独自のページ、次に一般的な言語（`es`）のページ、最後に英語を使用します。

- **ご自身のサーバー向け:** ページの Markdown を、同じファイル名（たとえば `locales\fr\help\03-cameras.md`）で `locales\<code>\help\` にコピーして、翻訳します。
- **LarisVMS に貢献する場合:** 送信方法については、[CONTRIBUTING.md](https://github.com/billacuda/LarisVMS/blob/main/CONTRIBUTING.md) をご覧ください。翻訳されたページは、ソースの `src/LarisVMS.Web/Help/<code>/`（たとえば `Help/es-AR/03-cameras.md`）に、`Help/en/` の英語ページと並んで保存されます。貢献されたページは LarisVMS に同梱され、訪問者が言語を選べる [larisvms.com/docs](https://www.larisvms.com/docs/) にも掲載されます。

ヘルプは、その言語がインストールされている（その `.json` ファイルがある）場合に、その言語で表示されます。ページ内の HTML はプレーンテキストとして表示されるため、書式設定には Markdown を使用してください。

### 翻訳を更新する

LarisVMS の新しいバージョンでは、テキストが追加されます。言語ページの**翻訳済み**列には、各言語が現在のテキストをどれだけカバーしているかが、**ヘルプページ**には、独自のテキストを持つヘルプページの数が表示されます。言語の横の**ダウンロード**では、不足しているテキストが英語で補完された、翻訳できる状態のファイルを入手できます。

アップロードする前にファイルを確認するには、`tools\locale-check.ps1 fr.json` を実行します。不足しているキー、このバージョンで使用されていないキー、英語のテキストと一致しない {プレースホルダー} が一覧表示されます。`-Help` に翻訳済みのヘルプページのフォルダー（たとえば `-Help locales\fr\help`）を指定して追加すると、それらも確認できます。まだ翻訳されていないページ、LarisVMS が使用しないファイル名、HTML、英語のページと揃っていない見出しが対象です。

### 翻訳をテストする

**設定 → 言語**の**言語メニューに擬似ロケールを表示**をオンにしてから、🌐 メニューで選択します。すべてのテキストが、アクセント付きで約 3 分の 1 長く、`[Ŝàṽé ··]` のように表示されます。プレーンな英語のまま表示されるテキストは、まだ翻訳できません。ご報告ください。ボタンや列からあふれるテキストは、より短い翻訳か、レイアウトの修正が必要です。

### 右から左へ書く言語

アラビア語、ヘブライ語、ペルシア語など、右から左へ書く言語では、鏡像のレイアウトになります。メニューは右に移動し、テキストとボタンは右揃えになります。カメラの映像、タイムライン、マップは反転されません。

### インストーラーを翻訳する

Web、Node、Proxy のインストーラーには、ソースコードの `installer\Common\Strings.en-US.wxl` に、独自の、ずっと短いテキストがあります。これを、言語名のファイル（たとえば `Strings.fr-FR.wxl`）にコピーし、ファイルの先頭にある注記に従ってください。そのあと、インストーラーは `.\build-installers.ps1 -Cultures en-US,fr-FR` でビルドされ、言語ごとにインストーラーのセットが作成されます。Windows 自体のインストーラーのボタン（次へ、戻る、キャンセルなど）は、すでに翻訳されています。

## 言語ファイルの場所

- `%ProgramData%\LarisVMS\locales` には、このサーバーで追加された言語が保存されます。アップグレードしても残ります。
- サーバーのインストールフォルダー内の `locales` には、LarisVMS に同梱されている言語が保存されます。このサーバーで追加されたファイルは、同じ名前のここのファイルより、行単位で優先されます。
- 英語は組み込みで、置き換えることはできません。

言語のアップロードや削除は、監査ログに記録され、設定を変更する権限が必要です。
