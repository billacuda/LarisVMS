# アクセシビリティ

キーボード、スクリーンリーダー、またはご自身の表示設定で LarisVMS を使用する方法について説明します。

## キーボード

すべてのページは、Tab を押すと表示される**メインコンテンツへスキップ**リンクから始まります。

| 場所 | キー |
|---|---|
| ライブとビューのタイル | Tab でタイルのコントロールに移動すると、そのコントロールが表示されます |
| PTZ ボタン | Enter または Space を押し続けると移動し、離すと停止します |
| タイムライン | 左右の矢印キーで時刻を微調整し、Page Up と Page Down でジャンプし、+ と - でズームします |
| 再生の現在時刻 | Enter で、正確な時刻を入力するフィールドが開きます |
| ゾーン、プライバシーマスク、速度測定、黒塗り | 矢印キーでカーソルを移動（Shift で大きく移動）し、Space でクリック、Enter で図形を確定、Backspace で最後の点を削除します |
| ダッシュボードとビューのレイアウト | 各項目に、移動とサイズ変更のボタンがあります |
| マップ | カメラで Enter を押すとマップの中央に配置され、そのあと移動ボタンを使用します |

図形の点を動かすには、その点で Space を押し、カーソルを移動して、もう一度 Space を押します。マウスでも同じです。点をクリックしてから、移動先をクリックします。

ドラッグせずに黒塗りの長方形を描くには、一方の角をクリックし、次に対角の角をクリックします。

## スクリーンリーダー

コントロール、フォームのフィールド、ステータスメッセージには、スクリーンリーダー用のラベルが付いており、エラーはページの読み込み時に読み上げられます。ビュー内のタイルで手動録画が開始または停止したことも、読み上げられます。

アクティビティページの正確な値は、表として利用できます。グラフの上にある表のオプションをオンにしてください。

映像自体は視覚的なものです。各映像にはカメラの名前が付いていますが、映像に何が映っているかを自動的に説明することはできません。

## 色なしでタイムラインを見る

タイムラインの区間は、色だけでなく、パターンでも区別されます。

- **空白:** 映像なし。
- **塗りつぶし:** 映像が録画された。
- **縞模様:** モーションまたはイベントのある映像。

## 表示設定

- **テーマ:** LarisVMS は、デバイスのライトまたはダークの設定に従います。または、ページ上部の 🌙 ボタンを使用します。
- **文字サイズ:** ブラウザーの既定のフォントサイズを大きくすると、ここにも適用され、ブラウザーのズームはすべてのページで機能します。
- **視差効果を減らす:** デバイスが動きの少なさを求めている場合、アニメーションはオフになります。
- **ハイコントラスト:** Windows のコントラストテーマに対応しています。

**設定 → ブランディング**では、選択した色が読みにくい場合に、LarisVMS が警告します。カスタムカラーは全員に適用されるため、慎重に選択してください。

## 更新を一時停止する

ダッシュボードの**更新を一時停止**を使うと、読んでいる間にウィジェットが変化しなくなります。ライブ映像は、それがこのページの目的なので、再生され続けます。

## 制限事項

- **字幕と音声解説:** カメラは字幕や音声解説を録画しないため、プレーヤーにはそのためのコントロールがありません。
- **見えない状態での描画:** カメラの映像上の図形はキーボードで描画できますが、配置は目視で行う必要があります。
- **タイルのタイムライン:** ライブタイルの小さなタイムラインは、マウスホイール、ピンチ、または + と - キーでズームします。再生の完全なタイムラインには、ズームボタンもあります。
