# 録画

録画モード、スケジュール、イベントタグ、プリロールとポストロール、セグメントの長さについて説明します。

## モード

すべてのカメラは、ノードに連続して録画します。**録画モード**が、どの映像を*保持*するかを決めます。

| モード | 保持する内容 |
|---|---|
| **連続** | すべて。 |
| **モーション** | モーションの前後の映像。モーションゾーン、カメラ自身のモーションイベント、連携、AI 検出のいずれかを使用します（[モーション](/Help/motion#source)をご覧ください）。 |
| **スケジュール** | 有効なスケジュールの時間帯の中で始まる映像。 |
| **イベント** | *録画を制御*がオンのイベントタグルールの前後の映像。 |
| **手動のみ** | [手動録画](#manual-recording)がオンでない限り、何も保持しません。それ以外の間、カメラはライブビューのみです。 |

保持されない映像は、保持期間を待たず、書き込まれた直後に削除されます。

モーション、スケジュール、イベントの各モードは、**フェイルオープン**です。カメラにモーションゾーン、スケジュールの時間帯、または録画を制御するルールが設定されるまでは、破棄せずにすべてを保持します。この状態になっている場合は、カメラのページに警告が表示されます。手動のみはフェイルオープンではありません。何も保持しないことが、その目的だからです。

グローバルなモードは**設定 → 録画の既定値**で設定し、カメラのページで上書きします。

## 手動録画

手動録画は、カメラの録画モードに関係なく、誰かが停止するまでカメラの映像を保持します。[ライブタイル](/Help/live-and-playback#live-tiles)の録画ボタン、または [API](/Help/api#recording) から開始します。再起動やアップグレードをまたいでオンのままになります。

これはカメラのモードと併用されます。モーションのカメラは、モーションを検出したとき、*または*手動録画がオンのときに映像を保持し、イベントは通常どおりタイムラインにタグ付けされます。連続のカメラでは、タイムラインに印が付くだけです。

- 映像はセグメント単位で保持されるため、録画の前後それぞれ最大 1 セグメント分も保存されます。プリロールとポストロールは適用されません。
- 保存された映像は、カメラの通常の保持期間に従います。より長く保持するには、[証拠ロック](/Help/live-and-playback#evidence-locks)を追加します。
- タイムラインには赤い帯として表示されます。色は**設定 → イベント**で変更できます。
- オフラインのカメラは、復帰するまで何も保存しません。録画はオンのままです。
- 録画ノードは、サーバーと一緒にアップグレードしてください。古いノードは手動録画に対応していません。

## プリロールとポストロール

モーションモードとイベントモードでは、**プリロール**はアクティビティの前の映像をどれだけ保持するか（誰かが入ってくるところが見えるようにするため）、**ポストロール**は終了後の映像をどれだけ保持するかです。

## セグメントの長さ

映像は、固定の長さ（既定は 60 秒）のファイルとして書き込まれます。再生では、選択した正確な時点から開始する前に、セグメントの一部をダウンロードする必要があります。セグメントを短くすると、高解像度カメラでのシークは速くなりますが、ファイルが増えます。長さを変更すると、カメラの録画が一時的に再起動します。

## スケジュール

カメラの**スケジュール**ページには、時間帯（曜日、開始時刻、終了時刻）が入ります。終了時刻が開始時刻より前の場合は、深夜 0 時をまたぎます。時刻は**録画ノードのローカル時計**を使用します。時間帯が意味を持つのは、スケジュールモードのときだけです。

## イベントタグ

カメラの**イベントタグ**ページでは、カメラからの ONVIF イベント（モーション、アラーム、分析、改ざん）を、タイムライン上の色付きの印に変換します。

- **開始トピック**: タグを開始するイベントです。カメラが実際に送信したものがすべて一覧表示される*観測されたトピック*から選択します。
- **停止トピック**: 任意です。開始トピック自体が true/false の状態を持つ場合（ほとんどのモーションとアラームのトピックが該当）は、空欄のままにします。カメラが開始と停止を別々のイベントで送信する場合に設定します。
- **録画を制御**: イベントモードまたはモーションモードで、このタグの前後の映像を保持します。

タグは、停止イベントが届いたときにのみ終了し、タイムアウトで終了することはありません。
