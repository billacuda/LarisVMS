# 概要

LarisVMS の構成要素（ウェブサーバー、録画ノード、メディアプロキシ、カメラ）がどのように組み合わさるかを説明します。

## 構成要素

| 構成要素 | 役割 |
|---|---|
| **ウェブサーバー** | LarisVMS のウェブアプリです。設定を SQL Server または MariaDB に保存し、UI と API を提供します。ダイレクトストリーミングがオンでない限り、ライブ映像と再生映像も中継します。*LarisVMS Web* という Windows サービスとして動作します。 |
| **録画ノード** | 録画を行う各マシンで動作する Windows サービスです。カメラから RTSP を取得し、ストレージパスにセグメントを書き込み、保持期間を適用し、モーション検出と AI 検出を実行し、正常性を報告します。1 台のサーバーに複数のノードを接続できます。 |
| **ビジョンサービス** | ノードの GPU（または CPU）で AI オブジェクト検出を実行する、任意の子プロセスです。ここでクラッシュしても、録画が止まることはありません。 |
| **メディアプロキシ** | ブラウザーとノードの間に置く任意の中継で、リモート拠点や低帯域幅の回線で使用します。 |
| **カメラ** | ONVIF カメラです。それぞれ 1 つの録画ノードに割り当てます。 |

## 映像の流れ

1. ノードは各カメラへ RTSP セッションを開き、`ffmpeg -c copy` で録画するため、再エンコードは行われません。
2. 映像は、ノードのストレージパス配下に、短いセグメントファイルとして書き込まれます（[録画](/Help/recording)をご覧ください）。
3. ライブビューと再生は、ノードが提供し、このサーバー、メディアプロキシ、またはブラウザーへの直接経路を通じて中継されます（[ノード](/Help/nodes#direct-streaming)をご覧ください）。

## プライバシー

LarisVMS はセルフホスト型です。映像と設定はお使いのマシンの中にとどまり、インストールに関する情報が収集または共有されることはありません。テレメトリーも、外部への自動送信もありません。定期的に行われる外部へのリクエストは、LarisVMS の GitHub リリースで新しいバージョンがないかを 1 日 1 回確認するものだけです（[更新](/Help/installation#updates)をご覧ください）。これはオフにできます。もう 1 つの組み込みダウンロードは、検出が初めて YOLOX モデルを使用する際に、そのプロジェクトの GitHub リリースから取得する YOLOX AI モデルです。ファイルをご自身でサーバーに配置した場合は、ダウンロードされません。[マップ](/Help/live-and-playback#map)ページの街路地図は、OpenStreetMap（またはご自身が選んだタイルサーバー）から、お使いのブラウザー内で地図画像を読み込みます。間取り図では読み込まれません。それ以外の通信は、すべてお使いのカメラ、ご自身のサーバー、およびメールやアラートチャンネルなどご自身で設定したサービスにのみ送られます。

## 設定の継承

ほとんどの設定は 3 つの階層に存在します。最も具体的なものが優先されます。

1. **カメラ**: カメラ自身の編集ページ。
2. **ノード**: **ノード**にある、そのノードの編集ページ。
3. **グローバル**: 対応する**設定**ページ。

空欄の項目（または「継承 — …」のオプション）は、1 つ上の階層の値を使用し、現在継承している値を表示します。

## ダッシュボード

ダッシュボードはウィジェットで構成されます。各ユーザーが自分のウィジェットを選び、レイアウトはアカウントに保存されるため、ほかのブラウザーでも引き継がれます。

- **カスタマイズ**（右上。ウィンドウが狭くて完全なグリッドを表示できない場合は非表示）でレイアウトのロックが解除されます。ウィジェットはタイトルバーでドラッグし、角でサイズを変更し、× で削除します。**ウィジェットを追加**には追加できるものがすべて表示され、**レイアウトをリセット**で既定に戻ります。完了したら**完了**をクリックします。
- カスタマイズ中は、各ウィジェットにドラッグせずに移動やサイズ変更ができるボタンが表示されます。
- **更新を一時停止**を押すと、読んでいる間にウィジェットが変化しなくなります。
- ほとんどのウィジェットは、カメラまたはノードの上位 10 件のリストです。たとえば、ストレージ使用量、フレームレート、帯域幅、最も古い映像、オフラインのカメラ、最後の録画からの経過時間、検出などです。時間枠（1h、24h、7d、30d）を持つものや、高い順と低い順を切り替えられるものもあります。
- ウィジェットのタイトルをクリックすると、完全なレポートが開きます。すべてのカメラまたはノードが 1 ページ 100 件で表示され、フィルターボックス、ノードフィルター、並べ替えできる列、CSV ダウンロードを備えています。
- **カメラのアクティビティ**は、あるカメラの過去 7 日間を、時間帯別のヒートマップで表示します。タイトルバーでカメラを選択し、タイトルをクリックすると、完全な[アクティビティ](/Help/live-and-playback#activity)ページが開きます。
- **最新の検出**は、最新のスナップショットを表示します。⚙ ボタンで、含める検出の種類を選択します。通常のモーション（何も識別されていないもの）は、チェックを入れない限りオフです。
- **最後の録画からの経過時間**は、連続録画に設定されたカメラが 5 分を超えて録画していない場合に、それを知らせます。
- カメラに基づくノードのウィジェット（カメラ数、オフラインのカメラ、フレームレート、ストレージの残り時間）では、カメラのないノードは除外されます。
- 表示されるのは、アクセス権のあるカメラのみです。**最近のアラート**は、アラートルールを管理できるユーザーにのみ提供されます。

ウィジェットは 1 分ごとに更新されます。

## スマートフォンでの利用

サイト全体が、スマートフォンのブラウザーで動作します。サイドバーは、左上の ☰ ボタンから開きます。

アプリとしてインストールするには、Android では Chrome でサイトを開き、⋮ メニューから**アプリをインストール**を選択します。iOS では Safari で開き、**共有 → ホーム画面に追加**を選択します。アプリは、ブラウザーのアドレスバーなしで、全画面で開きます。

インストールには、スマートフォンが信頼する証明書が必要です。新規インストール時の自己署名証明書を使用しているサイトは、ブラウザーでインストールできません。[証明書](/Help/security#certificates)をご覧ください。
