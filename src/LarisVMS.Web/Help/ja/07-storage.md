# ストレージと保持

録画の保存場所、保持期間、ウォーターマーク、アーカイブボリュームについて説明します。

## ストレージパス

各ノードは、ノードの編集ページまたはインストール時に設定する、独自の**ストレージパス**に録画します。グローバルなパスはありません。ストレージパスのないノードは何も録画せず、ノード一覧でフラグが付きます。

## 保持

**保持**は、映像を何日間保持するかです。**設定 → ストレージと保持**でグローバルに設定し、ノードごと、カメラごとに上書きできます。最も具体的な値が優先されます。0 で、映像を永久に保持します。

カメラには、GB 単位の**ストレージクォータ**も設定できます。超過すると、最も古い映像から削除されます。

## ウォーターマーク

**ウォーターマーク**は、ノードのディスクをどこまで満たしてよいかの厳格な上限です（既定は 90%）。これを超えると、ノードは最も古い映像を早期にアーカイブし、アーカイブできない場合は削除して、ディスクが上限を下回るまで続けます。この間、ノード一覧には**ストレージがいっぱい**と表示されます。

## アーカイブ

ノードには、SMB 共有や USB ドライブなど、任意の 2 つ目の**アーカイブパス**を設定できます。ストレージパスとは別の場所である必要があります。アーカイブをオンにすると、保持期間を過ぎた映像は、削除される代わりにアーカイブへ**移動**され、**アーカイブ保持期間**に達するまで保持されます。アーカイブ保持期間は、元の録画日から数えます。0 で永久に保持します。

再生、サムネイル、エクスポートは、どちらのボリュームからでも同じように機能します。ノード一覧には、両方のボリュームの空き容量と、残り日数の推定値が表示されます。推定値は、直近 24 時間の書き込みに基づいています。

## 残った映像

カメラを別のノードに移動した場合や削除した場合、古い映像は、保存期間を過ぎるまで、以前のノードに残ります。ノードのステータスの横にある ⚠️ の数は、そこにまだ映像が残っているカメラの数です。自動的に消えます。

## 暗号化

映像は、録画ノードのディスク上で暗号化できるため、盗まれたり廃棄されたりしたディスクからは何も読み取れません。既定ではオフです。

**設定 → 暗号化と署名**で**設定**します。

1. **マスターキーを作成。** このサーバーに保管され、暗号化されたすべての録画のロックを解除します。
2. 選択したパスフレーズで保護された、マスターキーの**バックアップをダウンロード**します。バックアップを入手するまで、暗号化をオンにすることはできません。ファイルとパスフレーズは、このサーバー以外の場所に保管してください。サーバーを再構築した場合、バックアップで**復元**することが、暗号化された映像を再び読み取る唯一の方法です。両方を失うと、映像は完全に失われます。
3. **暗号化する内容を選択:** **映像**（録画と双方向の通話音声）、または**映像、スナップショット、サムネイル**。これがすべてのカメラの既定値で、各カメラは自身のページ（**カメラ → 編集**のストレージ）で上書きできます。

各セグメントは、録画が完了した少しあとに録画ノード上で暗号化されるため、ディスク上で暗号化されていないのは、録画中のセグメントだけです。暗号化をオンにする前に録画された映像はそのままです。カメラのページの**既存の映像を暗号化**で、バックグラウンドで変換できます。あとで暗号化をオフにしても、暗号化された映像は読み取れるままです。

再生、サムネイル、スナップショット、エクスポートは、以前と同じように機能します。エクスポートされたファイルは、受け渡しを目的としているため、暗号化されません。録画ノードは、必要なときに各カメラの日次キーをこのサーバーから取得し、メモリ内にのみ保持するため、録画ノードがサーバーに到達できない間は、暗号化された録画を再生できません。
