# 動体検出

モーションの検出元、サーバー側モーション、ゾーン、モーショングリッドについて説明します。

## 検出元

カメラがモーションを報告する方法は、いくつかあります。

- **サーバー側モーション**: ノードが、モーションゾーンまたはモーショングリッド内で映像フレームを比較します。
- **カメライベント**: カメラ自身の ONVIF モーションイベント。
- **ベンダー連携**: たとえば Dahua / Amcrest スマートイベント。
- **AI 検出**: 検出された動いているオブジェクト。

カメラの**モーションの検出元**では、モーションモードが何を保持するかを決める検出元を、これらの中から*1 つ*選択します。同じイベントでタイムラインに重複したエントリが作られないようにするためです。**自動**では、設定されているものの中で最も豊富なものが選ばれます。イベントタグのルールと AI のオブジェクトラベルは、この選択に関係なく、常にタイムラインにタグを付けます。

## サーバー側モーション

カメラのページの**サーバー側モーション**は、ノード自身のピクセルモーション検出のオン/オフを切り替えます。ほかの検出元が録画を制御している場合でも、通常のモーションをタイムラインにタグ付けするフォールバックとして、オンのままにしておきます。使用する CPU を節約するには、オフにします。

## ゾーン

カメラの**ゾーン**ページには、2 つの方式があります。有効にできるのは一度に 1 つだけで、切り替えても、もう一方の設定は保持されます。

**グリッド**: セルをクリックしてマスクします（赤）。セルは、そこにモーションがあるとき琥珀色になります。マスクすべき、揺れる枝やちらつく照明を見つけるのに役立ちます。グリッドサイズを変更すると、マスクはクリアされます。

**ポリゴンゾーン**:

- **モーション**: 監視する領域。
- **無視**: 除外する領域（木、公道の歩道など）。無視ゾーン内のピクセルは、モーションゾーンと重なっている部分でも、数えられません。
- **プライバシー**: 黒く塗りつぶす領域。**🔒 プライバシーマスク**で描きます。これは、カメラがどちらのモーション方式（グリッドまたはポリゴンゾーン）を使っていても機能します。録画、ライブビュー（両方のストリーム）、スナップショット、エクスポートで隠されます。そのカメラの「プライバシーマスク」ビューで**プライバシーマスク内の検出も無視する**をオンにしない限り、背後で発生したイベントは通常どおり発生します（そのスナップショットは映像と同様にマスクされます）。マスクは描いた形に従い、端が透けないよう小さな余白が付きます。プライバシーゾーンのあるカメラは、録画中に映像が再エンコードされるため、CPU（ノードが対応している GPU を持つ場合は GPU）を多少使用します。
- **カメラ側モーション**のゾーンは保存できますが、まだ有効ではありません。

ゾーンの形を変えるには、一覧で選択して頂点をドラッグし、**保存**します。描画中は、右クリックで最後の点を削除します。一覧でゾーンにカーソルを合わせると、映像上で強調表示されます。頂点をクリックしてから、移動先をクリックすることもできます。

**感度**は、ゾーン内のピクセルのうち、変化する必要がある割合です。低いほど敏感になります。広いゾーンでは、実際の動きがゾーンのごく一部しか占めないため、低い値が必要です。低い値（3% 前後）から始め、風や照明の変化で反応する場合にのみ上げてください。
