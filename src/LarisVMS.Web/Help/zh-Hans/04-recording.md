# 录制

录制模式、计划、事件标签、预录和后录，以及片段时长。

## 模式

每台摄像头都会持续录制到其节点。**录制模式**决定*保留*哪些录像：

| 模式 | 保留 |
|---|---|
| **连续** | 所有内容。 |
| **移动侦测** | 移动前后的录像：来自移动侦测区域、摄像头自身的移动事件、某个集成，或 AI 检测（参见[移动侦测](/Help/motion#source)）。 |
| **计划** | 在已启用的计划时间段内开始的录像。 |
| **事件** | 在已开启*触发录制*的事件标签规则前后的录像。 |
| **仅手动** | 除非开启了[手动录制](#manual-recording)，否则不保留任何内容。其余时间摄像头只用于实时查看。 |

未被保留的录像会在写入后不久被删除，而不是等待保留期。

移动侦测、计划和事件模式是**失效放行**的。在摄像头设置好移动侦测区域、计划时间段或触发规则之前，它会保留所有内容，而不是丢弃。发生这种情况时，摄像头页面会发出警告。仅手动不是失效放行，因为什么都不保留正是它的用途。

在**设置 → 录制默认值**下设置全局模式，并在摄像头页面上覆盖它。

## 手动录制

无论摄像头的录制模式如何，手动录制都会保留摄像头的录像，直到有人停止它。使用[实时磁贴](/Help/live-and-playback#live-tiles)上的录制按钮或通过 [API](/Help/api#recording) 开始。它在重启和升级后仍保持开启。

它与摄像头的模式并行工作。移动侦测摄像头在看到移动*或*手动录制开启时保留录像，事件仍照常在时间线上添加标签。在连续摄像头上，它只会在时间线上标记。

- 录像按完整片段保留，因此录制前后最多各有一个片段也会被保存。预录和后录不适用。
- 保存的录像遵循摄像头的常规保留策略。添加[证据锁定](/Help/live-and-playback#evidence-locks)可保留更久。
- 它在时间线上显示为红色条带。在**设置 → 事件**下更改颜色。
- 离线的摄像头在恢复之前不会保存任何内容。录制保持开启。
- 请将录制节点与服务器一起升级。旧节点不知道手动录制。

## 预录和后录

在移动侦测和事件模式下，**预录**是活动之前保留多少录像（这样您能看到有人走进来），**后录**是活动结束后保留多少。

## 片段时长

录像以固定长度（默认 60 秒）的文件写入。回放必须先下载片段的一部分，才能从您选择的确切时刻开始。较短的片段使高分辨率摄像头的定位更快，但会产生更多文件。更改时长会短暂重启摄像头的录制。

## 计划

摄像头的**计划**页面包含其时间段：日期、开始时间和结束时间。结束时间早于开始时间表示跨越午夜。时间使用**录制节点的本地时钟**。时间段只在计划模式下有意义。

## 事件标签

摄像头的**事件标签**页面会将来自摄像头的 ONVIF 事件（移动、报警、分析、篡改）转换为时间线上的彩色标记。

- **起始主题**：启动标签的事件。从*已观察到的主题*中选择一个，它列出了摄像头实际发送过的所有内容。
- **停止主题**：可选。当起始主题自带真/假状态时（大多数移动和报警主题都是如此），请留空。当摄像头分别发送开始和停止事件时再设置它。
- **触发录制**：在事件或移动侦测模式下，保留此标签前后的录像。

标签只有在其停止事件到达时才会结束，绝不会因超时而结束。
