# 概览

LarisVMS 各部分如何协同工作：Web 服务器、录制节点、媒体代理和摄像头。

## 各个组成部分

| 组成部分 | 作用 |
|---|---|
| **Web 服务器** | LarisVMS 的 Web 应用。将配置存储在 SQL Server 或 MariaDB 中，提供界面和 API，并在未开启直连流媒体时中继实时和回放视频。以 *LarisVMS Web* Windows 服务运行。 |
| **录制节点** | 每台录制计算机上的 Windows 服务。从其摄像头拉取 RTSP，将片段写入其存储路径，执行保留策略，运行移动侦测和 AI 检测，并上报健康状况。一台服务器可以有多个节点。 |
| **视觉服务** | 节点的可选子进程，在节点的 GPU（或 CPU）上运行 AI 对象检测。这里崩溃永远不会使录制停止。 |
| **媒体代理** | 浏览器与节点之间的可选中继，适用于远程站点或低带宽链路。 |
| **摄像头** | ONVIF 摄像头。每台摄像头分配给一个录制节点。 |

## 视频如何流转

1. 节点向其每台摄像头建立 RTSP 会话，并使用 `ffmpeg -c copy` 录制，因此不会发生重新编码。
2. 录像以短片段文件的形式写入节点的存储路径下（参见[录制](/Help/recording)）。
3. 实时查看和回放由节点提供，并经由此服务器、媒体代理中继，或直接发送到浏览器（参见[节点](/Help/nodes#direct-streaming)）。

## 隐私

LarisVMS 是自托管的：您的视频和设置保留在您自己的计算机上，不会收集或共享任何有关您安装的信息。没有遥测，也不会向外回传。唯一的例行出站请求，是每天检查一次 LarisVMS 的 GitHub 发布页面是否有新版本（参见[更新](/Help/installation#updates)）；它可以关闭。另一项内置下载，是检测首次使用时从该项目的 GitHub 发布页面下载的 YOLOX AI 模型，除非您自己把文件放到服务器上。[地图](/Help/live-and-playback#map)页面上的街道地图会在您的浏览器中从 OpenStreetMap 或您选择的瓦片服务器加载地图图片；平面图则不会。其他所有内容只会发送到您的摄像头、您自己的服务器，以及您设置的服务（如电子邮件和警报渠道）。

## 设置继承

大多数设置存在于三个层级。最具体的一级优先：

1. **摄像头**：在摄像头自己的编辑页面上。
2. **节点**：在**节点**下该节点的编辑页面上。
3. **全局**：在对应的**设置**页面上。

留空的字段（或“继承 — …”选项）使用上一层级的值，并显示它当前继承的值。

## 仪表板

仪表板由小组件组成。每位用户选择自己的小组件，布局会保存到其账户，因此在其他浏览器上也会保持一致。

- **自定义**（右上角；当窗口太窄无法显示完整网格时隐藏）会解锁布局。拖动标题栏移动小组件，拖动角落调整大小，或用 × 移除。**添加小组件**会列出所有可添加的内容，**重置布局**会恢复默认。完成后点击**完成**。
- 自定义期间，每个小组件都有可以移动和调整大小的按钮，无需拖动。
- **暂停更新**可在您阅读时让小组件停止变化。
- 大多数小组件是摄像头或节点的前 10 名列表，例如已用存储、帧率、带宽、最旧录像、离线摄像头、距上次录制的时间和检测。有些带有时间窗口（1h、24h、7d、30d），有些可以在最高和最低优先之间切换。
- 点击小组件的标题可打开其完整报告：每台摄像头或节点，每页 100 条，带筛选框、节点筛选、可排序的列和 CSV 下载。
- **摄像头活动**以按时段划分的热力图显示一台摄像头过去 7 天的情况；在其标题栏中选择摄像头，点击标题可打开完整的[活动](/Help/live-and-playback#activity)页面。
- **最新检测**显示最新的快照。其 ⚙ 按钮用于选择包含哪些检测类型；普通移动（未识别出任何内容）默认关闭，除非您勾选它。
- **距上次录制的时间**会标出设为连续录制、但已超过 5 分钟没有录制的摄像头。
- 基于摄像头的节点小组件（摄像头数量、离线摄像头、帧率、剩余存储时间）会排除没有摄像头的节点。
- 您只能看到自己有权访问的摄像头。**最近的警报**仅提供给可以管理警报规则的用户。

小组件每分钟刷新一次。

## 在手机上

整个站点都可以在手机浏览器中使用。侧边栏通过左上角的 ☰ 按钮打开。

若要将其安装为应用，请在 Android 上用 Chrome 打开该站点，并从 ⋮ 菜单中选择**安装应用**。在 iOS 上，请用 Safari 打开，并选择**分享 → 添加到主屏幕**。该应用会全屏打开，没有浏览器的地址栏。

安装需要手机信任的证书。浏览器不会安装使用全新安装时自签名证书的站点；参见[证书](/Help/security#certificates)。
