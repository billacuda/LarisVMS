# 节点

录制节点：状态、流媒体路径、媒体代理、故障转移、维护和更新。

侧边栏中的**节点**会列出每个节点及其状态、地址、版本、摄像头数量和磁盘使用情况。点击节点可编辑其设置。**⋯** 菜单有以下操作：

- **重启服务**：重启节点的 Windows 服务，而不是重启计算机。录制会暂停几秒钟。
- **重置认证**：清除节点的签到令牌，用于错过心跳后一直认证失败的节点。对正常节点没有影响。
- **维护**：将节点的摄像头移到其备用节点，直到您关闭维护。
- **删除**：移除节点。其摄像头会变为未分配。录像不会被删除。

如果节点在最近 2 分钟内签到过，则为**在线**。⚠️ **时钟**警告表示节点的时钟与服务器相差超过一分钟，请检查其时间同步。

## 直连流媒体

默认情况下，所有实时和回放视频都经由 Web 服务器中继（**代理**）。使用**直连**时，浏览器会直接连接到每个节点自己的 HTTPS 端点，从而减轻服务器的负担。在**设置 → 实时查看**下设置模式，并可按节点覆盖。

直连模式需要浏览器可以访问的**客户端端点主机**，以及一个证书（节点页面上的 `.pfx` 路径）。**允许自签名**仅用于测试，因为查看者会看到浏览器警告。节点没有正常端点的摄像头会自动回退到代理。

## 来自服务器的加密连接

服务器和媒体代理通过节点实时端口（8554）上的普通 HTTP 访问每个节点的视频和控制路由，这在受信任的网络上没有问题。若要加密该流量，请在节点页面上开启**加密来自服务器的连接**，然后重启节点一次（**重启**）。节点会启动其 HTTPS 端点（如果没有 `.pfx`，则使用其自己的自签名证书）并上报该证书，服务器随后会固定它：服务器和代理只接受节点的这一个证书，媒体令牌也不再是地址的一部分。加密之后，节点的普通端口只响应 `/health`。

节点页面上的**已加密**列会为每个已加密的节点显示 🔒，为已开启但仍需重启的节点显示 ⏳。开关下方的状态会显示所用的证书，或服务器仍在等待它（在此之前，服务器会继续使用普通 HTTP，因此不会有任何功能停止工作）。默认关闭。为此使用的自签名证书永远不会提供给浏览器；直连流媒体仍然需要正式的证书。

## 代理

**媒体代理**是浏览器与节点之间的独立中继（`LarisVMS.Proxy`），适用于远程站点或低带宽链路。在**设置 → 媒体代理**下注册代理，然后在每个节点的页面上选择主代理和备用代理。浏览器会使用第一个正常的代理。

## 故障转移

为节点指定一个**备用录制节点**，当它宕机时，其摄像头会由备用节点录制，直到它恢复。“宕机”由该节点的伙伴节点、服务器和它的代理之间的投票来判定。**维护**会有意将其摄像头移过去并保持在那里。

当备用节点的 AI 硬件不同，或仅用于录制时，节点页面会发出警告。在这些情况下，故障转移期间检测可能变慢或暂停。

## 更新

节点和代理会从已批准的版本自动更新（参见[安装](/Help/installation#updates)）。**节点 → 更新与注册 → 自动更新**用于对所有节点开启或关闭此功能。

节点页面的**版本**部分显示每种节点正在升级到的版本，以及任何等待批准的版本，带有**批准**和**拒绝**。**版本历史**列出每个版本，包括已批准、已取代和已拒绝的。

## 服务器证书

**节点 → 更新与注册 → 服务器证书检查**决定节点和代理如何检查此服务器的 HTTPS 证书：

- **首次使用时信任**（默认）：受信任 CA 颁发的证书始终有效，包括续期和更换后的证书。自签名证书会在节点首次连接时被记住，只要它保持不变就会一直有效，即使过了到期日期。如果它发生变化，节点和代理会拒绝它，直到被重新注册。
- **仅受信任的证书**：只接受由受信任 CA 颁发、且与服务器名称匹配的证书。选择此项之前请先安装一个。
- **不检查**：任何证书。不安全：网络路径上的任何人都可以冒充服务器。

使用“首次使用时信任”时，节点会信任它首次连接时看到的任何证书。若要让它从最初的连接起就进行检查，请把**服务器证书检查**下显示的指纹传给安装程序：对 `install-node.ps1` 和 `install-proxy.ps1` 使用 `-ServerCertThumbprint`，对 MSI 使用 `SERVERCERTTHUMBPRINT=`。安装向导页面和媒体代理页面上的安装命令已经包含它。在反向代理之后，请改用反向代理所出示证书的指纹。

服务器为自己生成的自签名证书有效期为 10 年，不会自动更换。**重新生成自签名证书**会替换它；之后每个节点和代理都必须重新注册，节点页面会列出此后没有签到的节点。要重新注册节点，请再次运行节点安装程序，或在节点上运行 `LarisVMS.Node.exe --reset-server-pin` 并重启其服务（代理也有相同的选项）。

## 一次性注册代码

新节点和代理使用共享的**注册密钥**或一次性代码来注册。一次性代码只能注册一个节点或代理，之后即失效。未使用时，它会在 1 小时、24 小时或 7 天后过期。要创建一个，请前往**节点 → 更新与注册**，选择它的有效时长，并选择**创建代码**。代码只显示一次。请在安装程序要求输入注册密钥的地方使用它。**吊销**会取消尚未使用的代码。

共享密钥在被更改之前对每次安装都有效。一旦您使用一次性代码，请取消勾选**接受共享注册密钥**，这样旧脚本或电子邮件中的密钥副本就无法注册任何内容。已经注册的节点和代理不受影响。无论哪种方式，新节点在获得任何摄像头之前仍需等待批准。
