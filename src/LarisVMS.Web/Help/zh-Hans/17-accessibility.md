# 辅助功能

使用键盘、屏幕阅读器或您自己的显示设置来使用 LarisVMS。

## 键盘

每个页面都以**跳到主要内容**链接开头，按 Tab 键时会出现。

| 位置 | 按键 |
|---|---|
| 实时和视图磁贴 | 用 Tab 键可到达磁贴的控件，到达时控件会出现 |
| 云台按钮 | 按住 Enter 或空格键移动，松开则停止 |
| 时间线 | 左右方向键微调时间，Page Up 和 Page Down 跳转，+ 和 - 缩放 |
| 回放中的当前时间 | Enter 键打开一个字段，用于输入精确的时间 |
| 区域、隐私遮罩、测速点和涂黑 | 方向键移动光标（Shift 可加大步长），空格键点击，Enter 键完成图形，Backspace 键移除最后一个点 |
| 仪表板和视图布局 | 每一项都有用于移动和调整大小的按钮 |
| 地图 | 在摄像头上按 Enter 键将其放到地图中间，然后使用移动按钮 |

要移动图形上的某个点，请在其上按空格键，移动光标，然后再次按空格键。鼠标的用法相同：点击一个点，然后点击它应该移到的位置。

要在不拖动的情况下绘制涂黑矩形，请点击一个角，然后点击对角。

## 屏幕阅读器

控件、表单字段和状态消息都带有供屏幕阅读器使用的标签，页面加载时会播报错误。您视图中某个磁贴上的手动录制开始或停止时也会播报。

“活动”页面上的确切数值可以用表格查看：开启图表上方的表格选项即可。

视频本身是视觉内容。每个视频都以其摄像头命名，但画面显示的内容无法自动描述。

## 不依靠颜色查看时间线

时间线区段除了颜色之外，还通过图案来区分：

- **空白**：没有录像。
- **实心**：已有录像。
- **条纹**：有移动或事件的录像。

## 显示设置

- **主题**：LarisVMS 跟随您设备的浅色或深色设置，也可以使用页面顶部的 🌙 按钮。
- **文字大小**：浏览器中更大的默认字体大小在这里同样适用，并且浏览器缩放在每个页面上都有效。
- **减少动态效果**：如果您的设备要求减少动态效果，动画就会关闭。
- **高对比度**：支持 Windows 对比度主题。

在**设置 → 品牌**下，如果所选的颜色难以阅读，LarisVMS 会发出警告。自定义颜色适用于所有人，因此请谨慎选择。

## 暂停更新

使用仪表板上的**暂停更新**，可以在您阅读时让小组件停止变化。实时视频会继续播放，因为这正是该页面的用途。

## 局限性

- **字幕和音频描述**：摄像头不录制字幕或音频描述，因此播放器没有相关控件。
- **无法目视时的绘制**：摄像头画面上的图形可以通过键盘绘制，但放置位置需要靠肉眼判断。
- **磁贴时间线**：实时磁贴上的小型时间线可通过鼠标滚轮、双指捏合或 + 和 - 键缩放。回放中的完整时间线还带有缩放按钮。
