# 语言

以另一种语言显示 LarisVMS，并添加您自己的翻译。

## 选择语言

从任意页面（包括登录页面）顶部的 🌐 菜单中选择一种语言。您的选择会跟随您，应用于您登录的每台设备。只有安装了多于一种语言时，才会出现该菜单。

管理员在**设置 → 语言**下为尚未选择语言的所有人设置语言。保持为**浏览器的语言**，则改为跟随每个人的浏览器。

日期、时间和数字也会跟随语言。如果您的浏览器使用相同的语言但带有地区格式（例如英式英语），则会保留该地区格式。

警报和通知会以每个人自己的语言送达。团队渠道（发送到固定地址的电子邮件、Webhook、ntfy、Pushover、Slack 和 Teams）使用默认语言。审计日志保持为英文。

某种语言尚未翻译的文本会以英文显示。

## 添加语言

无需编程：一种语言就是一个文本文件。

1. 在**设置 → 语言**下，下载英文文本 **en.json**。
2. 翻译每行右侧的文本。左侧的键请保持原样。
3. 在**设置 → 语言**下上传该文件，或将其复制到服务器上的 `%ProgramData%\LarisVMS\locales`。请以其语言代码命名，例如 `fr.json`、`de.json` 或 `pt-BR.json`。

它立即可用，无需重启。无法读取的文件会连同原因一起列在“语言”页面上，LarisVMS 的其余部分继续正常工作。

### 需要保持原样的内容

- **大括号 { } 中的任何内容**都由 LarisVMS 填入，例如 `{camera}` 或 `{count}`。请把它移到句子中合适的位置，但不要翻译或重命名它。
- **少数标签**可能出现在文本中：`<code>`、`<strong>`、`<em>`、`<b>`、`<i>`、`<kbd>`、`<br>` 和 `<a href="…">`。请让它们仍然包围相同的词。其他 HTML 不被允许，并会显示为纯文本。
- 顶部的 **_meta** 部分包含该语言在 🌐 菜单中显示的名称（例如“Français”），以及您的姓名（如果您希望署名）。

### 复数

有些文本会随数字变化。英语有两种形式：

```json
"cameras.count_one": "{count} camera",
"cameras.count_other": "{count} cameras"
```

请添加您的语言所需的形式，使用以下结尾：`_zero`、`_one`、`_two`、`_few`、`_many` 和 `_other`。例如，俄语使用 `_one`、`_few` 和 `_many`。请始终包含 `_other`；在没有其他形式适用时会使用它。

### 帮助页面

帮助页面逐个文件翻译。每个页面保持英文文件的名称，因此其地址不会变化，您没有翻译的页面仍保持为英文。地区语言（`es-AR`）先使用自己的页面，然后是通用语言（`es`）的页面，最后是英文。

- **用于您自己的服务器**：将页面的 Markdown 以相同的文件名复制到 `locales\<code>\help\`（例如 `locales\fr\help\03-cameras.md`），然后翻译它。
- **为 LarisVMS 贡献**：关于如何提交，请参阅 [CONTRIBUTING.md](https://github.com/billacuda/LarisVMS/blob/main/CONTRIBUTING.md)。翻译后的页面保存在源代码中的 `src/LarisVMS.Web/Help/<code>/`（例如 `Help/es-AR/03-cameras.md`），与 `Help/en/` 中的英文页面并列。贡献的页面随 LarisVMS 一起发布，也会出现在 [larisvms.com/docs](https://www.larisvms.com/docs/)，访客可以在那里选择语言。

只要安装了某种语言（其 `.json` 文件），帮助就会以该语言显示。页面中的 HTML 会显示为纯文本，因此请使用 Markdown 来设置格式。

### 更新翻译

LarisVMS 的新版本会增加文本。“语言”页面上的**已翻译**列显示每种语言涵盖了多少当前文本，**帮助页面**则显示它有自己文本的帮助页面数量。语言旁边的**下载**会提供其文件，其中缺失的文本已用英文补全，可以直接翻译。

在上传文件之前检查它，请运行 `tools\locale-check.ps1 fr.json`。它会列出缺失的键、此版本未使用的键，以及与英文文本不匹配的 {占位符}。加上 `-Help` 并指定一个已翻译帮助页面的文件夹（例如 `-Help locales\fr\help`），还可以检查这些页面：尚未翻译的页面、LarisVMS 不使用的文件名、HTML，以及与英文页面不对应的标题。

### 测试翻译

在**设置 → 语言**下开启**在语言菜单中提供伪语言**，然后从 🌐 菜单中选择它。每段文本都会带上重音符号并加长约三分之一，例如 `[Ŝàṽé ··]`。仍以纯英文显示的文本尚无法翻译；请反馈。溢出按钮或列的文本需要更短的翻译，或修正布局。

### 从右到左书写的语言

阿拉伯语、希伯来语、波斯语和其他从右到左书写的语言会获得镜像布局：菜单移到右侧，文本和按钮向右对齐。摄像头画面、时间线和地图不会镜像。

### 翻译安装程序

Web、节点和代理安装程序有它们自己的、短得多的文本，位于源代码中的 `installer\Common\Strings.en-US.wxl`。请将其复制为以语言命名的文件（例如 `Strings.fr-FR.wxl`），并按文件顶部的说明操作。然后使用 `.\build-installers.ps1 -Cultures en-US,fr-FR` 构建安装程序，为每种语言生成一套安装程序。Windows 自带的安装程序按钮（下一步、上一步、取消等）已经翻译。

## 语言文件存放在哪里

- `%ProgramData%\LarisVMS\locales` 存放在此服务器上添加的语言。升级后依然保留。
- 服务器安装文件夹中的 `locales` 存放随 LarisVMS 提供的语言。在此服务器上添加的文件，会逐行优先于这里的同名文件。
- 英文是内置的，无法替换。

上传或移除语言会记录到审计日志，并且需要更改设置的权限。
