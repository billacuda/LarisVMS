# 摄像头

添加摄像头、摄像头列表、码流、设备设置、分组、多镜头设备和厂商集成。

## 添加摄像头

使用**摄像头 → 发现**扫描局域网中的 ONVIF 设备，或使用**摄像头 → 添加**输入设备服务 URL（例如 `http://192.168.1.50/onvif/device_service`）和凭据。然后 LarisVMS 会**探测**摄像头：读取其 ONVIF 功能和码流，并选择主码流和子码流。

请分配一个**录制节点**，否则摄像头不会录制。

## 摄像头列表

**摄像头**列出您能看到的每台摄像头。列标题下方的那一行可按任意列（如品牌、型号、节点或分组）筛选，表格上方的搜索框则按行内任意位置的文本筛选。筛选条件可以组合，**清除筛选**会重置它们。**列**用于选择显示哪些列。针对隐藏列的筛选会被忽略。

您的筛选、列、排序顺序和页面大小会保存到您的账户，因此在任何设备上再次登录时都会恢复。

勾选摄像头即可一次对多台进行操作：**将所选项重新分配到节点**，或对同一品牌和型号的摄像头使用**设备设置…**（参见[批量更改](#bulk-changes)）。**全选**只会选中符合当前筛选条件的摄像头。

## 重新探测

摄像头页面上的**重新探测**会重新读取其功能和码流。在摄像头自己的网页上更改分辨率、编解码器或固件之后，请执行此操作。在[设备设置](#device-settings)中所做的更改会自动重新探测。更改设备 URL 并保存时也会自动重新探测。**设置 → 摄像头设置**可以每天重新探测一次所有摄像头。摄像头是逐台探测的，因此廉价摄像头不会断开其录制会话。重新探测时，码流名称和启用标志会被保留。

## 码流

每台摄像头通常有一个**主码流**（全分辨率，用于录制）和一个**子码流**（较低分辨率，用于小型实时磁贴和 AI 检测）。展开摄像头页面上的**设备**可重命名或禁用某个码流。将鼠标悬停在码流上可查看其 RTSP URL。LarisVMS 使用添加摄像头时所用的地址，并保留摄像头上报的端口和路径，因此上报内部地址的摄像头（或冒充它的人）无法携带密码把录制节点引向别处。

## 设备设置

摄像头页面上的**设备设置**通过 ONVIF 更改摄像头自身的设置，因此您无需登录摄像头的网页。设置是从摄像头实时读取的，只显示它所支持的设置。

| 部分 | 设置 |
|---|---|
| **视频码流** | 每个码流：编解码器（H.264、H.265 或 MJPEG）、编码配置文件、分辨率、帧率、码率模式（CBR 或 VBR）、码率、质量和关键帧间隔 |
| **图像** | 亮度、对比度、饱和度和锐度；日夜模式；WDR；背光补偿；曝光模式；以及白平衡 |
| **音频** | 编解码器、码率和采样率 |

每个部分都有自己的**应用**按钮，并且只会发送您更改过的设置。应用码流或音频的更改会使码流重新连接，在录制中留下几秒钟的空白；随后 LarisVMS 会重新探测摄像头，录制节点会立即采用新格式。图像更改无需重新连接即可生效。

有些摄像头在码流之间共用同一组编码器设置。页面会注明这一点，因为更改其中一个会改变另一个。

H.265 和 CBR/VBR 的选择需要支持 ONVIF Profile T（Media2）的摄像头。在较旧的摄像头上不会出现这些选项。

## 批量更改

一次更改同一品牌和型号的多台摄像头：

1. 在**摄像头**上，筛选**型号**列，然后勾选这些摄像头（或**全选**）。
2. 点击**设备设置…**。仅当所有勾选的摄像头是同一品牌和型号时才可用。
3. 更改您需要的内容，并点击该部分的**应用**。

您也可以从某一台摄像头的**设备设置**页面开始，并在**同时将更改应用到**下选择同型号的其他摄像头。**固件不同**徽章会标出固件不同的摄像头，它们提供的选项可能略有不同。

页面显示第一台摄像头的当前设置。只有您更改的设置会发送给每台摄像头，因此每台摄像头自身的其余设置保持不变。码流按角色（主码流、子码流或第三码流）匹配。每台摄像头会根据自身的选项检查该更改，结果列表会按摄像头显示它是已应用、部分应用、已跳过（例如没有第三码流的摄像头）还是失败（例如离线）。**重试失败项**会向失败的摄像头再次发送该更改。

## 分组

分组将摄像头按站点、建筑和楼层组织。**顶层分组即站点**，其下的分组是建筑或楼层。一台摄像头可以属于任意数量的分组，只要它们都属于同一个站点。分组用于筛选、设置覆盖以及[摄像头访问](/Help/users#camera-access)。内置的*所有摄像头*分组始终包含每台摄像头。

## 多通道

有些设备在一个外壳里有多个镜头。当探测发现多个视频源时，摄像头页面会提供**拆分为 N 台摄像头**。此后每个镜头都成为自己的摄像头，拥有各自的录制和保留。现有摄像头成为通道 1，并保留其录像。

## 集成

有些功能无法通过 ONVIF 使用。集成（列在**设置 → 插件**下）会在探测期间根据摄像头的品牌和型号自动匹配，无需打开任何开关。例如，**Dahua / Amcrest 智能事件**集成会从摄像头自带的分析中读取人员和车辆检测。当集成生效时，摄像头的**设备**面板会显示。
