# 移动侦测

移动侦测来源、服务器端移动侦测、区域和移动网格。

## 来源

摄像头可以通过几种方式上报移动：

- **服务器端移动侦测**：节点在移动侦测区域或移动网格内比较视频帧。
- **摄像头事件**：摄像头自身的 ONVIF 移动事件。
- **厂商集成**：例如 Dahua / Amcrest 智能事件。
- **AI 检测**：检测到的移动对象。

摄像头的**移动侦测来源**会从中选择*一个*来决定移动侦测模式保留什么，这样时间线就不会为同一事件出现重复条目。**自动**会选择已设置的来源中最丰富的一个。无论如何选择，事件标签规则和 AI 对象标签始终会在时间线上添加标签。

## 服务器端移动侦测

摄像头页面上的**服务器端移动侦测**用于开启或关闭节点自身的像素移动检测。即使其他来源控制着录制，也请保持开启，以便在时间线上标记普通移动作为后备。关闭它可节省其占用的 CPU。

## 区域

摄像头的**区域**页面有两种方式。同一时间只有一种生效，切换时会保留另一种的设置。

**网格**：点击单元格以将其屏蔽（红色）。当单元格中有移动时会变为琥珀色，这有助于您找到需要屏蔽的摇晃的树枝或闪烁的灯光。更改网格大小会清除遮罩。

**多边形区域：**

- **移动侦测**：要监视的区域。
- **忽略**：要排除的区域（一棵树、一条公共人行道）。忽略区域中的像素永远不会被计入，即使它与某个移动侦测区域重叠。
- **隐私**：要涂黑的区域。请在 **🔒 隐私遮罩**下绘制，无论摄像头使用哪种移动侦测方式（网格或多边形区域），它都有效。它会在录像、实时查看（两个码流）、快照和导出中被隐藏。除非您在“隐私遮罩”视图中为该摄像头开启**同时忽略隐私遮罩内的检测**，否则其后的事件仍会照常发生（其快照像视频一样被遮罩）。遮罩遵循您绘制的形状，并带有小幅边距，以免露出边缘。带有隐私区域的摄像头在录制时会对视频重新编码，这会占用一些 CPU（若节点有受支持的 GPU，则占用 GPU）。
- **摄像头端移动侦测**区域可以保存，但尚未生效。

要调整区域的形状，请在列表中选中它并拖动其顶点，然后点击**保存**。绘制时，右键单击会移除最后一个点。将鼠标悬停在列表中的区域上会在图像上高亮它。您也可以点击某个顶点，再点击它应该移到的位置。

**灵敏度**是区域内必须发生变化的像素所占的百分比。越低越灵敏。大区域需要较低的值，因为真实的移动只覆盖其中一小部分。从较低的值（约 3%）开始，只有在风或光线变化触发它时才调高。
