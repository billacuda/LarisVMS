# Changelog Archive: v0.144.0 – v0.152.0

Archived entries from [CHANGELOG.md](../CHANGELOG.md), oldest read at the top or bottom the
same as the main file — nothing reordered, just moved. Format is unchanged: [Keep a
Changelog](https://keepachangelog.com/en/1.1.0/) / [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.152.0] - 2026-08-23

### Added

- Cameras > Groups cards are now collapsible.

## [0.151.1] - 2026-08-23

### Fixed

- Camera Access's group picker showed raw GUIDs instead of readable names.

## [0.151.0] - 2026-08-23

### Added

- A built-in "All Cameras" camera group that every camera belongs to unconditionally and can't be
  removed from.

## [0.150.2] - 2026-08-23

### Fixed

- Camera Access — choosing "camera group" or "single camera" as a grant's scope never revealed a
  picker, and saving always failed.

## [0.150.1] - 2026-08-23

### Fixed

- Cameras > Groups' "Manage cameras" popup repeated the same site-conflict warning next to every
  camera; now stated once.
- A nested group's card only indented its title text, not the whole card.

## [0.150.0] - 2026-08-23

### Fixed

- Recording gaps on Continuous-mode cameras — hours of footage recorded to disk but never reported
  to the server, due to an HTTP timeout being mishandled as a cancellation and silently ending the
  report loop.
- A brief storage outage could delete database rows for footage that still exists; added
  reachability/plausibility guards before trusting a "file missing" inference.

### Added

- Recovery import for footage on disk with no matching database row, closing the gap from the fix
  above automatically.

## [0.149.2] - 2026-08-23

### Fixed

- "A camera can only belong to groups under a single site" was confusing with no way to see or set
  a camera's site; site hierarchy is now shown wherever groups are picked.

## [0.149.1] - 2026-08-23

### Added

- IP allow lists for management/API traffic and for live view/playback, each independently
  configurable. Self-lockout guarded against.

## [0.149.0] - 2026-08-23

### Added

- REST API foundation + API keys — a machine credential for external automation, plus a monitoring
  status endpoint.

## [0.148.2] - 2026-08-23

### Fixed

- The previous fix for the fullscreen black-screen bug didn't actually close it; fixed properly by
  tracking fullscreen transitions from when they're requested rather than when confirmed.

## [0.148.1] - 2026-08-23

### Fixed

- Double-clicking a camera fullscreen on live view showed several seconds of black screen — a
  layout-breakpoint listener was destructively rebuilding every camera's session.

## [0.148.0] - 2026-08-23

### Added

- A camera can now belong to more than one camera group at once, as long as all its groups share
  the same top-level site.

## [0.147.4] - 2026-08-23

### Fixed

- Two collapsible admin panels were unreadable in dark mode.

## [0.147.3] - 2026-08-23

### Added

- Camera Access grants can now be edited in place, not just added and removed.

## [0.147.2] - 2026-08-23

### Fixed

- Cameras > Groups had no way to add a camera to a group from that page.

## [0.147.1] - 2026-08-23

### Changed

- Permissions > Roles cards are now collapsed by default.

## [0.147.0] - 2026-08-23

### Added

- Roles & permissions overhaul, final pass — auto-expiring role assignments.

## [0.146.0] - 2026-08-23

### Added

- Roles & permissions overhaul, pass 4 — PTZ priority arbitration between roles.

## [0.145.0] - 2026-08-23

### Added

- Roles & permissions overhaul, pass 3 — the full permission matrix, with real enforcement points
  and grants seeded for the new built-in roles.

## [0.144.0] - 2026-08-23

### Added

- Roles & permissions overhaul, pass 2 — scope-tier enforcement on Camera Access grants.
